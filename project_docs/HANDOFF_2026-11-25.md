# FAECO 研究交接（2026-11-25）

## 1. 项目是什么

FAECO 面向已详细布线设计的 ECO 标准单元面积回收。在真实详细重布线、寄生重提取、原 I/O、三角 setup／hold、独立 DRC／天线及 SEC 验收下，测同一墙钟预算内的合格回收，以及达到相同实际回收面积的用时。投稿目标是 IEEE TCAD。中文 v3 是工作主稿，实验优先。[现行口径](CANON.md)

## 2. 当前做到哪一步

可以完善中文稿。建议主线为**换门引起冲突的在线诊断与限时面积回收**。AES 同物理端点已有可写的省时证据，UART 已有可写的面积与时间权衡，riscv32i 划出了共享排序后动态反馈的当前证据边界。论文的跨设计收益主张还需要独立对照。本轮完成原文对照、证据整理和交接，源码、论文和配图未作改动。[投稿判断](evidence/tcad_publication_assessment_20261125/REPORT.md)

工程冻结标签仍为 v22。后续实验证据和工作稿以 main 的 CANON 为准。交接前证据锚定提交 74a4c8dcce35a7427597a919233273283a9a7343，交接记录与它一同由 main 提供。仓库工作机为 Toylog，Windows PowerShell，WSL Ubuntu 用于 EDA。整理时未见运行中的 OpenROAD 或 Yosys 进程，riscv32i 矩阵状态为 complete。工作区既有夹具输出、QA 预览及一份历史英文 PDF 未跟踪，接手提交时按路径添加。

## 3. 已完成的关键工作

| 设计 | 已核的主要结论 |
|---|---|
| SKY130HD AES | 同调度同验收端点，现场诊断计费后，固定后端省 72–84 秒，FAECO 后端省 158–164 秒。在线 FAECO 在 720 秒和 6 逻辑请求上限内回收 67.5648 µm²，固定为 33.7824 µm²，但固定先到较小面积。[八臂交叉对照](evidence/tcad_ibex_20261123/AES_FACTORIAL_REPORT.md) |
| ASAP7 UART | 两序最高回收 FAECO 0.83106、强单门 0.77274、固定 0.33534 µm²。到同实收 0.77274 µm²，FAECO 较单门早 104–106 秒。单门在三个预设小面积阈值先到。[墙钟对照](evidence/tcad_wallclock_schedule_20261125/REPORT.md) |
| SKY130HD riscv32i | 前九门实布回收 75.072 µm²，三角时序过原门，独立 DRC／天线 0、SEC 4559/0。同排名的 720 秒六臂全部验收完毕。固定和 FAECO 均回收 75.072 µm²，单门 57.5552 µm²。固定与 FAECO 的共同实收首达差不超过 0.67 秒，反馈未触发。[六臂证据](evidence/tcad_rank_alignment_20261125/REPORT.md) |

## 4. 当前阻塞与风险

- AES 同端点省时目前只有一个开发设计的交叉对照。UART 与 riscv32i 已参与规则选择。动态反馈相对共用排序的固定批次仍缺独立收益验证。具体未决项见 OI-105。[未决记录](OPEN_ISSUES.md)
- SKY130HD JPEG 在原 SDC 下 SS 绝对 hold 不合格。ASAP7 Ethmac 在原 TT／SS 视图有 max slew 违规，独立 DRC 资格未完成，两者均没有进入正式候选试验。[JPEG 资格](evidence/tcad_holdout_20261123/JPEG_CONTROL_REPORT.md) · [Ethmac 与留出计划](evidence/tcad_wallclock_schedule_20261125/REPORT.md)
- 现有外部实测是历史 OpenROAD 原生回收和自实现冻结寄生 LR。正式限时端点缺现代外部 sizing 代码同台结果。TritonSizer 是可查的公开实现，输入、库和导出兼容性尚未验证。[文献与基线](evidence/tcad_publication_assessment_20261125/REPORT.md)

## 5. 下一步

1. 按原约束资格挑独立电路并冻结候选池与原验收规则。用同样的排序和批宽，比较常规按标记重试、简单几何邻网预放行、候选现场 DRC 标记诊断。优先测是否能复现同端点省时，照常记录没有命中冲突的情况。
2. 用同平台与验收重跑 OpenROAD 原生回收，并对 TritonSizer 做兼容预检。对每一臂记录全费用、时间内最大合法面积、共同实收首达、每角 WNS／TNS 和 hold、DRC／SEC。可比端点一并记录功耗。
3. 在预登记的独立设计上，用同排名与后端复测 FAECO 对固定三门。完整报告分叉与未分叉的设计，根据实际分叉和端点差异决定动态反馈在论文中的角色。
4. 中文稿先纳入文献差异、AES 配对、UART 曲线和 riscv32i 同榜结果。待独立结果再确定摘要和结论宣称范围。
