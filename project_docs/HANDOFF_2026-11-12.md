## 2 项目演变历史（接手者只需知道这些）

### 2.1 Phase 1：预布局门级 ECO（2026-10-14 前）

- 中文论文 r28（`project_docs/CANON.md` §1 裁定 1–9）
- 核心机制：覆盖优先调度 + 加权排序 + 失效反馈
- 主要局限：理想线网判据系统性废掉 B 类缓冲插入

### 2.2 Phase 2：机制审查与预注册实验（2026-11-09 ~ 2026-11-12）

- **方向 A**：物理档解锁 B 类 — 证伪（spef 线载模型结构缺陷）
- **方向 B**：判定带补布局离散 — 已入文（r116）
- **方向 C**：排序监督换布局后档 — 预证伪（r30 已测决策级未触发）
- **五轮预注册实验**：P/E/A6j/K/All — 全部 H2 FAIL（判决能改、端点不转）
- **结论**：「动作粒度 < 测量分辨率」，换判据档位/接受口径都改不了。机制无廉价改进路径。

### 2.3 Phase 3：方向转折——布局后 ECO vs Resizer（2026-11-11）

- 用户指示"做新 SOTA、不要论述论文"
- 对标 OpenROAD resizer、E-Layout、GoalEvolve
- **P1**：FAECO-P vs resizer，8 例 ISCAS89 → 0/8 胜（残差 −0.34 ns），resizer 动作量大 10–40 倍
- **Hybrid 组合臂**：5/8 胜但均值差 +0.024 ns 未过门
- **P1′ pilot**：在 pre-CTS resizer 终点上重入 FAECO → 残差 +0.079 ns（通过），但不能外推到 post-CTS 设定

### 2.4 Phase 4：Recovery（当前，2026-11-12）

- **核心发现**：逐实例审计发现 Resizer 的 67% 改动对 WNS 无贡献
- **Faeco-Recovery 算法**：解析 Resizer 的 routed.v → 识别所有改动 → 逐候选独立 STA 评估回退的 WNS 影响 → 贪心累积回退 + 安全系数 1.5× + 后验证循环
- **结果**：14 电路，136/202 可回退，14.0% 面积回收，WNS 保持
- **生产级 CLI**：`code/scripts/recover_area.py`（8 秒完成 s382）
- **跨基准族**：ISCAS89 + ITC-99 两族一致性成立

## 5 关键决策与边界

### 5.1 可以写的（论文中允许的主张）

- "Resizer 67% 的改动对 WNS 无可测贡献"（有逐实例证据）
- "Faeco-Recovery 在保持 WNS 的前提下回收 14.0% 面积"（有 14 电路证据）
- "两基准族之间一致性成立"（ISCAS89 + ITC-99）
- "Resizer 的面积膨胀 48.8%，我们回收其中一部分"
- "Recovery 算法是确定性、可复现的"
- "逐实例审计是一种新的 ECO 评估方法论"

### 5.2 不能写的

- "Faeco-Recovery 的 WNS 在任何布局下都优于/等于 Resizer"（s820/s953 跨布局退化）
- "我们的 Recovery 比 Resizer 好"（我们是在 Resizer 之后运行）
- "Recovery 能做跨设计迁移"（目前每电路独立评估，无学习组件）
- "面积回收是免费的"（有安全系数 1.5×，可能留一些可回退但不安全的改动）
- "在所有基准族上都测试了"（只测了 ISCAS89 + ITC-99，没有 ASAP7/OpenCores/工业基准）

### 5.3 已否决、不得重开

1. 在理想线网判据（不带 `--physical-gate`）下继续改机制
2. 用 `--physical-gate` 的 spef 线载模型当真实物理（已证伪）
3. GNN 打分器（池内 AUC 0.479242 < kind_only 0.555062）
4. 自适应时限（R² 0.0977）
5. beam 回退 / 加带 / pin swap / JOINT 加深
6. 每实例预算分配 / 扩覆盖 8→10000 / 映射族统一 0.70
7. 用 OpenROAD（非独立 `sta`）跑布线后 STA
8. "换布局判据就能提高质量"、"gate 用理想档量子 0.01"
9. 只把动作做大就能提高质量

## 6 环境坑（接手者必读）

| # | 坑 | 症状 | 修法 |
|---|-----|------|------|
| 1 | MSYS 路径转换 | `D:/path` → `D:\d\path`（双 d） | `export MSYS_NO_PATHCONV=1` |
| 2 | Bash heredoc 执行 | 中文文档内容被当 shell 命令 | 长脚本用 `script_path` |
| 3 | `ops_bash` 执行器故障 | `EXECUTOR_UNAVAILABLE: Niubash execution tree link count mismatch` | 重试 1–3 次 |
| 4 | `compile.ps1` 字体坑 | 从 `build/` 跑导致 `./fonts/` 不存在 | 直接从 `paper/zh/manuscript/` 跑 `lualatex` |
| 5 | `edit` 工具行尾 | 把文件行尾全部转成 CRLF | 对混合行尾的文件要事后修复 |
| 6 | 浏览器提示 git 行尾 | `core.autocrlf` 为空 → `git add` 全行 diff | `git -c core.autocrlf=input add <path>` |
| 7 | `estimate_parasitics -placement` | 不设 `set_wire_rc` 则完全不生效 | 先设 `set_wire_rc -layer met2 -signal` / `-layer met4 -clock` |
| 8 | 布线后 STA | OpenROAD 跑 STA 报 `ORD-2010` | 必须用独立 `sta` |
| 9 | 成本读数 | `--workers` 不同导致 STA 计数不可比 | 成本只在同 workers 的臂间比较 |
| 10 | 端点缓存 | 只按 (arm,circuit,util) 键控 | 必须带 netlist sha256 |
| 11 | Resizer 输出格式 | `write_verilog` 扁平化输出不能塞回标准流程 | Recovery 用 Resizer 自己的 SPEF + STA |
| 12 | `run_resizer_one` 输出 | 内部拼接 circuit → 双层目录 | `RESIZER_DIR` 不要包含 circuit 名 |
