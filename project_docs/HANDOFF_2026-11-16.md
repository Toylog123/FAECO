## 核心指标公式

- **面积回收率** = (A_R − A_F) / (A_R − A_0)，其中 A_0=CTS前面积，A_R=Resizer后面积，A_F=最终面积
- **ΔWNS** = WNS_FAECO − WNS_Resizer_CONTROL（+表示FAECO WNS更好）
- **修复量%** = |ΔWNS| / (|baseline_WNS| − |Resizer_WNS|)，即ΔWNS占Resizer修复量的百分比
- **安全门**：max_degradation = 0.015ns（数值容差1e-6ns）
