# FAECO 总体机制相关工作核验

日期：2026-11-13。代码审查基点：e46ccdf。本轮为定向叙述性文献调研与实际调用链审计，不是系统综述；没有新 EDA、SEC、算法收益或论文修改。

## 1. 研究对象纠正

FAECO 不能被概括为“允许 WNS 损失若干 ps，再挑面积更小的点”。应比较完整研究链条：**时序/结构驱动区域构造 → 多类型候选与作用边界 → 相互影响下的搜索与调度 → 实际物理反馈 → 功能及物理验收**。可调 WNS 预算属于约束与接受政策，不能代表全部机制。

本轮发现多个整体或局部高度相近的先例。它们说明这个整体问题具有明确研究背景，也意味着“区域+多动作+组合+反馈”这个模块清单本身不能证明新颖性。需要具体算法和归因实验，不能据单个模块已有先例就否定整个项目。

## 2. 整体机制对照

本轮只作机制比较，不直接比较不同论文的百分比收益。总面积改善、功耗改善、TNS 改善与 Resizer 净新增面积回收率的分母不同。

## 3. 我们实际已经有什么

逐代码调用审计见 MECHANISM_AUDIT.md。当前有三条尚未统一的链：

1. 旧 FAECO 外循环：报告路径/锥与 cut 区域、多类动作、联合候选、STA 后端、事务提交与可配置失败反馈。论文受控配置没有同时打开所有选项。
2. 历史 recover_area：比较修复前后同名实例的 master 差分，以此回退、排序、组合复测与回滚，使用既有 SPEF；不是读取完整操作事件日志，未调用完整区域机制。
3. 新 budgeted_recovery：固定参考与可调预算、有限组合搜索、合格终点档案。真实 52 点适配器目前只重筛历史端点；组合搜索尚未接在线物理 evaluator。

因此，整体研究对象确实比预算筛选复杂，但不能把三条链画成已经统一运行并产生收益的系统。已有重布线/新寄生提取实验驱动可复用，尚需正式接入。当前历史端点面积结果不能转记为新组合搜索收益。

## 4. 可检验的贡献位置

目前最值得检验的是：**面向修复后面积回收，利用结构与物理反馈构造具有互补作用的候选，并在有限实际验证成本下选择动作组合，使给定 WNS 损失范围内的面积回收优于原生恢复及强贪心。** 这是研究假设，不是已证明的新颖性。

贡献必须回答至少一个具体问题：为何该区域/候选构造发现简单方法遗漏的可行修改；如何识别并利用修改之间的非加性；为何把昂贵验证分配给这些组合比常见排序、迭代贪心或等预算 beam 更有效。换名字、增加参数、串联模块或多跑物理工具都不足以回答。

保留 Resizer 前端符合当前用户目标。RL-CCD 等先例也表明，复用成熟后端与提出独立决策机制可以共存；独立贡献应在自己的决策及其效果归因上建立，不要求重写全部工具。

## 5. 调研导出的实验判据（尚未注册新运行）

| 对照 | 固定条件 | 推翻主张的结果 |
|---|---|---|
| 原生恢复、强多轮贪心、现有 beam、拟议整体机制 | 同一 Resizer 终点、候选合法域、约束、最终物理流程与预算 | 贪心在同成本下追平，则不能宣称联合选择优势 |
| 完整候选 vs 历史 edit 清单；两边用同一选择器 | 固定实际验证成本并给足简单基线多轮机会 | 所有增益仅来自扩大候选池，则贡献归候选构造，不能归搜索 |
| 组合/交互反馈开关；区域/覆盖策略开关 | 分别做组件消融，缓存与失败工具调用单列 | 关闭机制结果不变，或仅增加工具调用才改善，不能宣称该机制有效 |
| 预算曲线与完整约束跨设计 | 固定 Resizer 参考；B=0/5/10/20ps；hold 门不变，TNS 辅助 | 补足约束后优势消失、只在单设计出现，则整体优势未成立 |

工具成本需同时报实际 STA/route/SEC 启动数、失败、缓存与墙钟；内核 callback 数不等于实际 STA 次数。静态候选不是有效收益。先把约束、完整解析与物理 adapter 补齐，再冻结新矩阵，不能沿用已暂停 25 候选旧草案直接宣称新整体实验。
