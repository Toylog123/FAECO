# 工艺无关局部窗口化布线前 DRC 预检（`1.0 × H_row`）零漏报审计与双工艺 720 RAW s 正反序对照报告（2026-11-26）

本报告记录面向 IEEE TCAD 的局部窗口化布线前 DRC 冲突诊断机制（[boxed_drc.py](boxed_drc.py)）的完整验证：先通过全部历史不重复请求完成零漏报与零位移反驳性审计，随后在 **7 nm 独立留出设计 `asap7/aes`**（6 臂同排名正反序，同步将强单门基线也升级为窗口化预检）与 **130 nm 高冲突设计 `sky130hd/aes`**（4 臂正反序）上执行 720 RAW s 独占串行端到端对照与独立核验（关联 [OI-105](../../OPEN_ISSUES.md)）。

## 1. 机制与几何不变式

- **窗口定义（零工艺魔数）**：起点 `CONTROL` 已通过独立全块 DRC=0 验收；原地降尺寸 `swapMaster` 仅修改目标实例引脚几何、不移动任何邻居实例；擦除直连信号网只减少金属图形。因此，任何新增预检违例必局限于被编辑实例外围。本方法从 OpenDB 动态读取当前工艺的标准单元行高 $H_{\text{row}}$（SKY130HD 自动为 `2.72 µm` / `2720 DBU`，ASAP7 自动为 `0.27 µm` / `270 DBU`），对每个被编辑实例的 bbox 四边外扩 **`1.0 × H_row`**，裁剪至 `DieArea`，迭代合并重叠/相邻窗口后调用 OpenROAD 内置 `drt::check_drc -box`，再按 `(violation_type, bbox, srcs)` 规范去重输出至既有 `drc_neighbor_evidence()`。
- **签核门零妥协**：仅**布线前冲突诊断**使用局部窗口；候选布线完成后的独立终检 `unlocked_drc` 依然执行**全芯片全块 `drt::check_drc`**，配合 FF/TT/SS 三角 setup/hold/电气、天线=0 与 Yosys 全网表 SEC。

## 2. 反驳性检验：历史全部 14 组不重复批次零漏报审计

审计脚本：[audit_boxed_drc_recall.py](audit_boxed_drc_recall.py) · 审计收据：[BOXED_DRC_RECALL_AUDIT.json](BOXED_DRC_RECALL_AUDIT.json)（CPU 0–5，单线程）。

- **原地零位移实证**：全部 37 组历史回放（SKY130HD AES 9 组 × 3 档 halo + ASAP7 AES 5 组 × 2 档 halo）中 `moved_other_insts = 0`（37/37）。
- **SKY130HD AES（全部 9 组历史不重复批次，3–9 门，累计 56 个真实 DRC marker）**：
  - `0.5 H_row / 1.0 H_row / 2.0 H_row` 三档均实现 **56/56（100.0%）精确 marker 匹配**与 **100.0% 精确释放邻网集合匹配**（0 漏报、0 误报）。
  - 在 `1.0 × H_row` 下，单次预检由 **13.94–14.93 s 降至 2.27–4.90 s（3.04×–6.31× 加速）**。
- **7 nm ASAP7 AES（全部 5 组历史不重复批次，1–9 门）**：
  - `1.0 H_row / 2.0 H_row` 两档均 0 误报；在 `1.0 × H_row` 下，单次预检由 **43.16–45.84 s 降至 2.73–9.36 s（4.61×–16.69× 加速）**。
