# 严格时序门下的面积回收：s382 四阶段物理研究

2026-11-13。当前接受一个保守单动作端点：**完整映射单元面积下降0.594530321%，propagated setup WNS、TNS改善，hold不变，完整两态SEC通过**。它证明当前设定存在面积与时序同时改善的点；尚未建立自己的联合机制优于简单方法，更不代表ICCAD投稿就绪。

## 用户目标与验收口径

在固定Resizer CONTROL基础上优化面积，并要求setup WNS、setup TNS、hold WNS全部不下降；1e-6ns只用于数值精度，不是允许时序退化的预算。面积统计全部Liberty已知功能实例，包括转义名FF；只排除逐实例核验无引脚的3026个physical taps。每个物理端点均包含102功能实例（其中21个FF）、335个pin binding。

各候选从相同OpenDB/原SPEF入口应用明确的逻辑目标，合法化、清除普通信号/时钟路由、完整重布线15迭代、重新提取RC，再用该端点自己的网表与SPEF测量ideal和propagated STA。主判据取propagated结果。所有41个新端点均通过预期完整结构、支持规则DRC零、当前配置slew/cap报告无违例的核验；时序不合格仍全部保留。

## 机制启示与下一门

1. 原回收中最差路径可切换到没有任何改动cell的路径；其新提取寄生和传播延时发生变化。候选是否落在原关键路径上，不能代替最终物理验证。详见`pathdiag/REPORT.md`。
2. 单动作前向选择确实得到可行点，而大面积联合回收及三种补偿仍失败。因此现阶段应保留安全基线，联合机制必须用额外净面积收益证明其价值。
3. 同功能更大驱动档不保证给定时序弧更快。Stage D的路径/Liberty归因见`pathdiag/JOINT_ATTRIBUTION.md`；补偿提案需要实际弧、slew/load及下游作用的判断，不能只按覆盖数和尺寸档位选。
