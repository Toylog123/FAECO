## 五、ICCAD机制缺口及必须实验

- **设计缺口**：历史回退、排序、完整解析、最终物理检查都是必要组件，单独不构成已建立的新算法。拟议自有机制若为“全局时序预算下的净面积联合选择”，必须写出变量/候选互斥、路径或端点约束、交互估计、解法、复杂度及实际回滚边界；并有能够被消融的独立设计。
- **首要反驳**：在同候选与相同实测预算下，简单面积优先安全贪心或最优单动作能否达到相同/更好的面积？若是，联合选择贡献未建立。当前9点无可行增益，不能继续在该池调风险分数来制造算法价值。
- **联合有效性**：需实际证明某些可行组合优于所有对应简单顺序/单动作，或更少成本找到同收益。独立Δ相加只能作proposal；实际可行性必须测联合端点。收益归因要区分扩大候选池与改变选择器，至少包含同完整候选池的去联合/去预算/固定排序消融。
- **强基线与成本**：原生recover_power及合理参数/重复轮次、同candidate generator的面积/时序安全顺序、有限预算简单search，以及适用的interaction-safe恢复方法。固定相同起点、Liberty/SDC/clock/物理流程，分别报告候选生成、实际STA、完整route/RCX、SEC、历史监督获取成本；不能以offline共享label只算新prefix次数来声称端到端加速。
- **可迁移性**：先在s382完成资格，再按事先门槛扩到s953/b07/b02及更大设计、独立实现和必要角；同一网表的25目标不是25个独立电路。跨族映射/约束不同需分层报告。至少覆盖零动作/无可行恢复、长扇出、狭窄hold余量和已收敛起点。
- **约束门**：完整SDC、约束覆盖、IO模型、max slew/cap及clock/FF相关检查须在其科学作用域内成立。当前负setup点只能说违例不扩大，不能叫timing closure。完整约束未建立前，正结果只能作为原clock-only模型下的可复现候选资格，不能作为完整设计安全的主结论。
