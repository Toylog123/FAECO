本证据包逐项回应模拟审稿（Major Revision）提出的全部 P0/P1 核心质疑，涵盖双工艺真实 `.tlef` DRC 规则核验、3 次重复 RCX/STA 确定性审计、既有收据 Hold 容差敏感性与 18 项池实例唯一性审计、同 $1.0\times H_{\mathrm{row}}$ 窗口后端的公平基线与组件消融、**Hybrid FAECO（有界乐观全池探针 + 自适应微批次回退）**四设计实测、绝对时序收敛（Timing-closed）基准验证、7 nm 扩展尺度/零重叠引脚偏移 DRC 审计，以及批宽 $b$ 与池规模 $K$ 参数敏感性实验。

## 1. 双工艺真实 `.tlef` 规则覆盖核验与 3 次 RCX/STA 确定性

- 收据：[LEF_AND_DETERMINISM_AUDIT.json](LEF_AND_DETERMINISM_AUDIT.json) · [OFFLINE_RECEIPT_AUDIT.json](OFFLINE_RECEIPT_AUDIT.json)
- **SKY130HD（$H_{\mathrm{row}} = 2.72\,\mu\text{m}$，`sky130_fd_sc_hd.tlef`）**：全栈 `li1`（`0.17 µm`）、`mcon`（`0.19 µm`）、`met1`（`0.28 µm`）、`via`（`0.17 µm`）、`met2`（`0.28 µm`）、`via2`（`0.20 µm`）、`met3`（`0.40 µm`）、`via3`（`0.20 µm`）、`met4`（`0.40 µm`）、`via4`（`0.80 µm`）、`met5`（`1.60 µm`）全部满足最大成对间距半径 $\le 1.60\,\mu\text{m} < H_{\mathrm{row}}$；引脚层 `li1`/`met1`/`mcon` 最大半径仅 `0.28 µm`（$9.7\times$ 余量）。
- **ASAP7（$H_{\mathrm{row}} = 0.27\,\mu\text{m}$，`asap7_tech_1x_201209.lef`）**：全部引脚层与中下层信号层 `V0`–`V7`、`M1`–`M7` 满足最大成对间距半径 $\le 0.072\,\mu\text{m} < H_{\mathrm{row}}$（其中标准单元引脚层 `M1–M3` 仅 `0.018 µm`，达 $15\times$ 余量；`M4/M5` EOL 间距 `0.024 µm`、`within = 0.040 µm`、PRL 表上限 `0.072 µm`）。客观边界：高层全局/电源层 `M8`/`M9`（PRL `1.0 µm`）与 `Pad`（`3.0 µm`）大于 $H_{\mathrm{row}}$，但原地单元替换仅改变底层引脚与障碍几何（$\mathcal{L}_{\mathrm{pin}}$），不触及高层电源/全局层，从而为命题 1 给出精确的层作用域条件 $\max_{\ell\in\mathcal{L}_{\mathrm{pin}}} r_{\mathrm{drc}}(\ell)\le H_{\mathrm{row}}$。
- **3 次同版图 RCX + 三工艺角 STA 确定性**：`asap7/uart` 与 `sky130hd/aes` 3 次独立重提取去日期 SPEF 逐字节一致，FF/TT/SS Setup/Hold 读数跨次极差严格为 `0.000 ps`，证明 $\varepsilon_h = 0.001\text{ ps}$ 不受提取随机抖动干扰。
- **既有收据 Hold 容差敏感性与池唯一性**：四设计 18 项池均为 `18/18` 互异实例（无同实例重复计入）；`0.001 / 0.01 / 0.1 / 1.0 ps` 离线敏感性显示：`sky130hd_aes_boxed` 8/19（`0.001/0.01 ps`）→ 4/19（`0.1 ps`）→ 0/19（`1.0 ps`），`asap7_aes_boxed` 2/16（`0.001 ps`, `-0.0022 ps`）→ 0/16（`≥0.01 ps`），`asap7_uart` 64 → 48 → 18 → 0 / 136，`sky130hd_riscv32i` 0/30。

## 4. 绝对时序收敛（Timing-closed）基准、7 nm 扩展 DRC 审计与 `b`/`K` 参数敏感性

- 收据：[TIMING_CLOSED_DRC_SENS_VERIFIED.json](TIMING_CLOSED_DRC_SENS_VERIFIED.json)（SHA-256 `04e55044…`）
- **绝对时序收敛基准（`asap7/uart @ 500 ps`）**：冻结参考三工艺角 Setup WNS 为 `+255.85 / +190.42 / +30.29 ps`，Hold WNS 为 `+50.31 / +67.50 / +54.05 ps`（FF/TT/SS 均严格非负）。在 1% 预算（`5.0 ps`）与 720 s 内：`窗口单门` `0.68526 µm²`（11/18，AUC `0.3631`）、`窗口固定微批次` `0.33534 µm²`（6/18，AUC `0.2395`）、**`窗口 FAECO`** **`0.83106 µm²`（13/18，70.4% 池，1.052% 功能单元面积，AUC `0.4561`，去重命中 2 次）**，且最终交付版图三工艺角 Setup/Hold 仍全部严格非负（Timing-closed）。
- **7 nm 扩展尺度与零重叠引脚偏移 DRC 审计**：在 `asap7/uart` 与 `asap7/aes` 上测试 18–120 门降尺寸及 6–18 门零重叠原地水平镜像引脚偏移（`setLocation` 保持严格包围盒），全部 14 组均与全块 `check_drc` 精确一致（`0 FN, 0 FP`）；客观揭示 7 nm 分层网格化布线（M1 仅单元内引脚、信号线位于 M2/M3+）使布线前违例稀少，且在万门级 `asap7/aes` 上实现 `2.97×–7.05×`（6–18 门）与 `1.82×–1.14×`（60–120 门）加速，而在仅 797 线网的小模块 `asap7/uart` 上多盒调用开销使加速比降至 `0.60×–1.22×`（明确给出窗口化加速的规模阈值边界）。
- **`b` 与 `K` 参数敏感性（`asap7/uart`，同一 $1.0\times H_{\mathrm{row}}$ 窗口后端，720 s）**：
  - 批宽 $b$（固定 $K=18$）：`b=1` `0.68526 µm²`（AUC `0.3718`）、**`b=2` `0.83106 µm²`（AUC `0.5261`，16 评）**、**`b=3` `0.83106 µm²`（AUC `0.4909`，18 评）**、`b=6` `0.72900 µm²`（AUC `0.3018`，21 评，6 去重）、`b=9` `0.68526 µm²`（AUC `0.2849`，20 评）、`b=18` `0.74358 µm²`（AUC `0.3350`，20 评）——清晰呈倒 U 型，证实 `b ∈ {2, 3}` 为最优工作点。
  - 池规模 $K$（固定 $b=3$）：`K=9` `0.49572 µm²`（7/9，73.9% 池，AUC `0.3414`）、`K=18` `0.83106 µm²`（13/18，70.4% 池，AUC `0.4909`）、**`K=36` `1.50174 µm²`（19/36，55.1% 池，1.901% 功能单元面积，AUC `0.7216`，23 评）**——证实主实验 $K=18$ 是跨设计统一保守基线而非算法回收上限。
