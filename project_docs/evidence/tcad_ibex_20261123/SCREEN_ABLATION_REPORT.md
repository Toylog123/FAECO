# SKY130HD 候选筛选、调度消融与留出验证

## 冻结口径

使用原 SKY130HD Ibex 共同 hold 修复端点，沿用原始 SDC、详细布线与 RCX 的三角读法。主档保留原周期 1% 的逐角相对 WNS 与 TNS 门、绝对 hold 非负和相对 hold 非退化、无新增电气违规、DRC=0、功能面积下降以及非空全网表 SEC。对拒收原因分别记录 WNS、TNS、绝对 hold 和相对 hold。 [登记](../EXPERIMENT_REGISTRY.md#2026-11-23-tcad-sky130hd-screen-ablation-holdout-v1)

新筛选只使用已存在的兼容实例。每个实例保留 TT Liberty 面积最大的合法较小档，按最大输出扇出升序、面积减量降序和动作标识排序。只用冻结 ODB 和 CONTROL SPEF 做逐候选 TT 筛选，保留满足 TT WNS/TNS、绝对 hold 和电气门的候选。最多花 32 次冻结寄生 STA，得到 18 个可用候选即停止。所有筛选时间记入使用它的策略。原面积排序与新筛选规则各供单门、固定三门和自适应三门三种调度使用，组内排序相同。六次候选上限、720 s 公共窗口及 CONTROL 功能面积 0.01% 的同面积目标固定。

所有新实验计时使用 `CLOCK_MONOTONIC_RAW`。物理比较每臂独立运行，DRT/RCX、三视图 STA、SEC 和调度等开销逐项记录。另保留搜索阶段和计入筛选后的两种时间。T01 使用 FIFO `place2749`、寄存器堆 `place2755` 和前两个低扇出筛选候选作为物理探针。测试失败或零收益均纳入汇总。 [T01 命令](SCREEN_PILOT_COMMAND.txt)
