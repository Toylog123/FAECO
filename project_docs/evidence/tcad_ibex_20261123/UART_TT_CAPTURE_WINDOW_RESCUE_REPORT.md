# UART 两组六门的 TT 捕获时钟邻域补救

目标是检验 UART 六门 `04` 和 `05` 能否从原拒收 ODB 在 TT 最差路径的捕获时钟邻域补救。两组的物理面积潜力均为 0.34992 µm²。已验收的同起点前沿为 0.26244 µm²，净面积潜力为 0.08748 µm²。此前复用同一原 ODB 的全解锁重入分别追加 33.790 与 33.028 RAW s，SS 通过但 TT 仍拒收。 [原补救证据](HOLD_REENTRY_RESCUE_REPORT.md) · [全解锁收据](../tcad_holdout_20261123/UART_RESCUE_EXISTING_ODB_RESULTS.json)

## 开跑前规约

从原完成布线的 TT min 报告读出最差端点，用原 DEF 的 CLK 端子绑定其时钟叶网。两组都是 `uart_rx_inst.busy$_SDFFE_PP0P_` 从自身 Q 经两门回到 D，发射与捕获共用叶网。`clknet_3_7__leaf_clk` 同时服务原 SS 最差路径的接收寄存器。固定时钟根和上游，不把共有时钟时间变化当作捕获独占的调节。

允许动的时钟网仅为该叶网，空间范围取其原中心线与通孔锚点的包围框加三条有效轨距。信号网仅选 TT 路径上完整落在叶网范围且位于捕获单元 DEF 原点 1 µm 方窗之内的线段网络。多偏移轨合并后计算实际相邻轨间距。严格检查其余线网、元件和特殊网的 DEF 几何，允许网的最终中心线与通孔锚点也必须留在对应窗内。无新换门、置放或 pin access。

先做保留现有布线的局部开放，若未过门，从同一拒收 ODB 再做一次，仅移除窗口内的末级 D 引脚反馈网的原线，并在同一个范围内重布。任何未过门的实跑均计费，第一次已通关的对象不再加第二项。新进程保持原 ASAP7、CPU 0–5、四线程、同一时钟和 I/O，单次 DRT 路由超时 75 s。最终仅在归一副本移除保护标志，校验几何无改动后进行独立全块 DRC／天线、原 FF／TT／SS setup、hold、电气及 SEC。按追加 RAW 总费用与以前已实测的全解锁比较。净面积从已验收前沿计算，两个候选的回收不可叠加。

## 主试结果

两组选出同样的时钟叶网以及 `_0103_`（D 端反馈线）和 `_0120_` 两条短信号线。共有 789 条其它已布线网保护，反馈网 `net38` 超出数据窗，保留在保护网中。捕获端 DEF 原点为 (11826, 10530) DBU，有效轨距给出的裕边为 144 DBU。时钟窗为 (10773, 9765) 到 (14661, 15579)，数据窗为 (10826, 9765) 到 (12826, 11530)。

保留线与擦掉 D 端反馈线再布这四次的规范化布线都完全复现原拒收端点，没有一条网在终态发生几何变化。原三角时序逐项相同，TT 和 SS 仍拒收。四次终态均通过独立全块 DRC、天线与诊断 SEC 567/0。两组的主试累计分别为 20.912 和 21.217 RAW s，低于全解锁，但未形成可贡献面积的终态。 [主试收据](../tcad_holdout_20261123/UART_TT_CAPTURE_WINDOW_RESULTS.json)

## 补充诊断及付费比较

主试出现零改线后，使用完全相同的范围单独擦除并重布时钟叶，保留两条数据线的原线。两组都只改变了叶网，789 条保护网几何保持，接线、网表和原 TT/SS 最差路径身份均保持，终态独立 DRC／天线为零且诊断 SEC 567/0。TT/SS 相对门下限分别为 67.501115 和 54.051915 ps。

| 候选 | 原拒收 TT／SS（ps） | 全解锁重入 TT／SS（ps） | 限域重布叶网 TT／SS（ps） |
|---|---:|---:|---:|
| `04` | 67.499568／53.985191 | 67.499568／54.206403 | 67.453064／53.856794 |
| `05` | 67.500686／54.018234 | 67.500693／54.239460 | 67.494489／53.879221 |

重布叶网时，提取的叶网总 C 分别由 1.47498 增至 1.57315 fF、1.46184 增至 1.56014 fF。两角 hold 均比原拒收点更差。共享叶网的几何有变化，结果仍须以实际数据路径和时钟传播重新验收。这两个物理结果未显示局部时钟重布的通用调节方向。 [叶网补充分支](../tcad_holdout_20261123/UART_TT_CAPTURE_LEAF_REROUTE_RESULTS.json)

| 候选 | 全解锁实测（RAW s） | 两项限域主试累计（RAW s） | 补充叶网（RAW s） | 限域全部累计（RAW s） | 净回收（µm²） |
|---|---:|---:|---:|---:|---:|
| `04` | 33.790 | 20.912 | 14.471 | 35.383 | 0 |
| `05` | 33.028 | 21.217 | 14.901 | 36.118 | 0 |

主试累计包含一次范围定位费用。表中的全解锁来自前次同机器、同拒收 ODB 的实际执行，两批费用按观察记录。仅单独考虑叶网尝试，两组也是 TT/SS 拒收。全部限域尝试仍有 0.34992 µm² 的物理面积潜力，联合验收均未通过，净回收均为零。 [全解锁收据](../tcad_holdout_20261123/UART_RESCUE_EXISTING_ODB_RESULTS.json)

## 判断与后续

这两个候选不值得采用本次限域补救。两项主试虽快，但输出原端点。实际重布叶网后两角 hold 更差，累计费用也分别比全解锁多 1.593 和 3.090 秒。后续优先以已通过 SS 的全解锁端点作起点，固定时钟几何，先核对 TT 自反馈的 setup 余量，再对数据反馈支路做有方向的最小延迟补偿。仍保留原各角门与 DRC／SEC，并扣除补偿的面积和成本。
