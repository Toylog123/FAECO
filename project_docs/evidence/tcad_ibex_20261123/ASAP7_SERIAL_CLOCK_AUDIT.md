# ASAP7 串行复跑时钟核查

## 采样口径

主收据用同一个 WSL `time.monotonic()` 度量每臂首次达标时间和阶段耗时。抽查以 Windows QPC 持续计时器和 WSL `CLOCK_MONOTONIC_RAW` 独立对比。Windows QPC 频率为 10,000,000 tick/s。QPC 前后打点用于包住 WSL 调用。采样只读取时钟，单次外部调用小于 1 s，没有额外 EDA。

```powershell
$before=[Diagnostics.Stopwatch]::GetTimestamp()
$hostUtc=[DateTimeOffset]::UtcNow.ToUnixTimeMilliseconds()
wsl python3 -c 'import time; print(time.time(), time.monotonic(), time.clock_gettime(time.CLOCK_MONOTONIC_RAW))'
$after=[Diagnostics.Stopwatch]::GetTimestamp()
Write-Output "$before $after $([Diagnostics.Stopwatch]::Frequency) $hostUtc"
```

## 原序组与时钟敏感性

第 5 点在原序组开始前约 52 s，第 10 点在最后一臂结束后约 10 s。第 7、8 点围住原序组两臂交接。第 5 点到第 10 点跨越 1426.707–1427.208 Windows QPC 秒，WSL RAW 推进 1426.949880 s，WSL MONOTONIC 推进 1491.640014 s。该区间 MONOTONIC 对 QPC 的速率比为 1.04515–1.04551。
