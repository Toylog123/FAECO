# 单次 pin access 的 ODB 重入检验

上轮 GCD 和 Ibex 的单次 pin access 保持了同一候选的 DEF、网表、寄生、三角 STA、DRC 和 SEC。保存的 ODB 字节不同，二次 ECO 是否受影响仍待实测。[前轮 A/B](PIN_ACCESS_AB_REPORT.md)

## 冻结比较

用前轮正式通过的 A 和 B 各自保存的 routed ODB 作为第二次局部 ECO 的输入。A 表示原来的显式与详细布线内置两次 pin access，B 表示只执行详细布线内置的 pin access。第二次 ECO 只应用预定的新增动作。四臂按 A→A、B→B、A→B、B→A 串行运行。先录同配方路径的单次时间差，交叉两臂用于识别第一步保存的数据库状态是否影响第二步。

第二次物理几何参照为输入端点本身，setup、hold、电气门、原始 IO/SDC、三视图 Liberty、RCX 和 SEC 的 gold 均继续绑定原始冻结 CONTROL。保持四线程和 64 次 DRT 迭代上限，使用 CPU 0–5。GCD 整组限 600 秒，Ibex 限 1600 秒。每次均重新做 DRT/RCX 和三个 STA 视图。达到原验收门后才计入正式 SEC。物理完整而未通过验收的候选可以补原冻结网表的诊断 SEC，该时长单独记录。所有评估均无物理缓存。

四次 DRT/RCX、12 次 STA、四次 SEC，物理缓存为零。四臂的 DEF、网表、去日期 SPEF、DRC、电气及完整三视图 STA 记录一致。三角无新增负 setup 端点，DRC=0，新增面积减量为 3.7536 µm²，累计 15.0144 µm²。保存的 ODB 有三个不同的字节摘要，两条交叉路径的 ODB 字节相同。

重入的三视图 hold WNS 为 +358.957364、+430.852687 和 +343.348683 ps，均保持相对原冻结起点不回退。与原冻结起点一次性运行相同四个编辑相比，网表字节相同，DEF、SPEF 和时序发生变化。一次性运行的 TT/SS hold 为 +429.642266/+338.568507 ps，较起点分别下降 1.084438 和 4.336809 ps。此处的相对 hold 拒收在两种 pin access 配方的重入中都消失。四臂重入均直接触及四条网，实际八条网有几何变化，组件放置不变。A→A 与 B→B 的时间差 2.364 RAW s 是本实验单次同序观测。

四次均完整完成 DRT/RCX、三视图 STA，DRC=0，物理缓存为零。四臂 DEF、网表、去日期 SPEF、改线清单、三视图 WNS/TNS、电气和负 setup 端点逐值相同。保存的 ODB 有三个摘要，A→B 与 B→A 的 ODB 字节相同。物理减量累计 43.792 µm²，第二步减少 21.2704 µm²，四条路径都没有交付合格面积。四次诊断 SEC 绑定原冻结 CONTROL，分别证明 13648 个点且未证明数为 0。

四臂同时触发 TT TNS 门和新增最大电容违规。TT TNS 从 CONTROL 的 −40674.379420 ps 降到 −41704.012688 ps，损失 1029.633268 ps，超过 1000 ps 门限，TT 新增 6 个负 setup 端点。TT WNS 损失 3.228529 ps，未越过 WNS 预算。FF/TT/SS 的 hold WNS 为 +288.151947/+466.107042/+116.513466 ps，均保持原门。与原冻结起点一次性完成相同六个动作相比，网表字节一致，DEF、SPEF、时序和接受结果发生变化。一次性累计的 TT TNS 为 −40614.320795 ps，联合验收与 SEC 通过。

TT 新违规引脚为 `_12540_/Y`。STA 测得电容 0.075289480 pF，限制为 0.074167997 pF，裕量 −0.001121485 pF。其输出网 `_02456_` 的 DEF 走线未变，SPEF 总电容从起点及原累计结果中的 0.0659667 pF 增至 0.0661425 pF。二次 ECO 直接触及 11 条网，实际 28 条网几何有变。这个证据将新增电容问题定位到寄生变化，TT 全设计 TNS 损失的来源未作逐路径归因。

## 兼容性结论

在这两组重入中，固定第二步配方时，第一步 A/B 保存的 ODB 均产生相同的可观测几何、寄生和验收结果。改变第二步配方也保留了这些结果。GCD 四次通过，Ibex 四次因同一组 TT 门拒收。多步重入和从原冻结起点一次性派发累计动作的物理结果不同，需要分别记账。原始输出 ODB 的字节差依然存在，本轮也未覆盖第三次 ECO。

GCD 的 A→A 到 B→B 节省 2.364 RAW s。Ibex 节省 27.733 RAW s，其中 DRT/RCX 节省 25.612 RAW s。这是两个固定第二步候选的单次顺序配对，Ibex 的时间止于正式拒收，诊断 SEC 单列。完整搜索速度及其合法面积交付另由对应的整臂试验衡量。
