# SKY130HD GCD 的单邻网预放行对照

在已冻结的同一三门提议上，各实跑一次几何择一和已知邻网预放行。几何择一未避开首轮三处短路。首轮直接放行已知邻网则清零并省去复修。两者最终均因 TT 相对 Hold 下降 0.022620794 ps 拒收，合格回收为 0 µm²。

## 固定条件与选网

两臂沿用[常规、窗口与全块三臂的控制输入](GCD_WINDOW_DIAGNOSIS_REPORT.md)，固定替换排名 13–15 的三个复用器。各自重新通过严格零改动资格与 SEC 262/0。使用原嵌入导引、四线程 DRT、一次显式 pin access、1.1 ns 周期及原三角物理门。每臂最多一条请求，720 RAW s 含 39.206442669 s 共用预筛。选网和运行串行使用原 CPU 6–11 与共享 EDA 锁。

几何臂用 OpenDB 中的原实例包围盒，对冻结 DEF 中具有 li1 或 met1 布线的非时钟信号网计算最小欧氏距离，排除十条直连网。距离按 DEF 布线路径中心线和锚点计，不使用线宽、via 面几何或 RECT 补片。独立解析复现 470 条网的完整顺序。六条零距离并列网为 `_073_`、`dpath.a_lt_b$in1\[6\]`、`net238`、`net240`、`net241`、`net242`。先按登记的词典序选择 `_073_`，再读取历史标记邻网的名次。已知臂使用此前独立 DRC 标记确定的 `net242`，并在首轮仅放行这一条网。该臂是事后干预。

几何臂首轮独立 DRC 报告与原三臂相同，均为 `net242` 与 `net266` 之间的三处窗内 met1 短路。几何臂在一次复修中保留 `_073_`，再追加 `net242`，独立 DRC 清零。实布的两条放行网均发生几何变化，其余保护网保持不变。已知臂的首轮即通过独立 DRC，规范化后的路由 Tcl 与常规臂复修一致，ODB、DEF、网表、统一日期后的 SPEF 和逐角时序均重现该参考端点。几何臂复修的 ODB、DEF、SPEF 和完整三角视图与单网放行端点不同。

两臂最终 TT Hold WNS 均为 +430.704083509 ps，下降幅度均超过 0.001 ps 相对容差。1 条候选在各臂都完成但未交付，候选 SEC 工序均未触发。两次首轮放行数量相同，选中的网决定了本例是否需要复修。几何分数将两个选项列为同距，实跑覆盖词典序首选和事后已知的邻网。时间仅作两次实际运行记录。
