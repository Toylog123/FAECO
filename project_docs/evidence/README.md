# 证据规范

本目录保存**不可变**实验证据与结论交叉表。论文/报告中的每条结论必须能追溯到这里的证据包。

## 证据包自包含要求

每个证据包（`evidence/<域>/<实验>/<日期标识>/`）应包含：

- `README.md`：摘要、基线绑定、运行命令、结论口径（估测 vs 实测）
- `input/`：复现所需的最小输入（必要时）
- 原始输出：日志、报告、数据文件
- `SHA256SUM` 或 manifest：文件清单哈希

## 规则

1. 证据包一经发布不可改写；新结果另建新包。
2. 登记到 `INDEX.md`。
3. 禁止把旧基线数据拼进新包。
4. 中间/生成文件可 git-ignored，但原始输出与 README 必须可追溯。

## 多级目录结构（每级一个维度）

证据包按 **版本 → 类型 → 实验 → 日期批次** 多级组织：

```text
project_docs/evidence/
└── v1/                    # 一级：版本
    ├── rtl/
    │   └── example_case/
    │       └── 20260811_r01/   # 四级：日期_批次（自包含证据包）
    └── power/
        └── hit_rate/
            └── 20260811_r01/
```

详见 `project_docs/FILE_ORGANIZATION.md`。

## 实验登记表

- `EXPERIMENT_REGISTRY.md`：记录**所有做过 / 正在做的实验**，避免重复做。做新实验前先查。
