# 论文-证据交叉表

> 目的：论文 / 报告中的每个数字与结论都能追溯到 `project_docs/evidence/` 中的证据包，防止数字失真、改数字不同步。
> **改论文任何已报告数字前，先在本表定位对应行，同一次编辑更新证据引用。**

## 交叉表

| 论文位置（章节 / 表格 / 图） | 数字 / 结论 | 证据包路径 | 基线 | 口径（估测 / 实测） | 复核状态 |
|------------------------------|-------------|------------|------|--------------------|----------|
| §IV-B 表 3 | … | `evidence/rtl/...` | [基线ID] | 实测 | 待复核 |
| … | … | … | … | … | … |

## 使用规则

1. 每条数字必须指向一个证据包；无法指向的不得写入论文。
2. **路径只在本表记录**：论文正文**不写任何工程路径**（evidence / experiments / code 等）；路径映射统一在本交叉表。
3. 口径列明确"估测 / 实测"，与 `versioning.md` 的结论边界规则一致。
4. 论文最终投稿前，逐行复核"论文数字 = 证据数字"。
5. 交叉表随论文 + 证据同步维护，登记到 `INDEX.md`。
