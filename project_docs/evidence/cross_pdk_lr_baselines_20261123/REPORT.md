# 跨方法横向对比与跨工艺扩展实验报告（2026-11-23）

## 1. 任务背景与评测口径边界

本证据包记录围绕中文主稿进一步补强的三项实测横向对照与跨工艺验证工作：

1. **OpenROAD 原生负裕度门限证伪（`s382`）**：验证在 `CONTROL` 负松弛起点（`WNS = -0.8485 ns`）下，放宽原生工具松弛裕度与显式允许违例后是否仍触发零动作锁定。
2. **Track A：经典拉格朗日松弛离散降尺寸基线（`LR_DOWNSIZE`，10 电路 SKY130）**：在完全相同的 `CONTROL` 布线后起点、$B=10\text{ ps}$ 预算与 `detailed_route + RCX + propagated OpenSTA` 物理闭环下，实测 5 轮冻结寄生子梯度 LR 基线（Chen/Chu 1999 & Flach 2014 范式）的物理真实可行性。
3. **Track B：ASAP7 7 nm 多阈值电压两万门工业基准跨工艺验证（`aes_cipher_top`，MLCAD26）**：扩展工具无关候选枚举器至任意多文件 Liberty 工艺库（含未加引号 `cell (...)`、`dont_use` 过滤及多 Vt 同足迹保持），在 20,097 实例（19,534 标准逻辑/时序单元 + 563 tap cell）`aes_cipher_top` 上开展 OpenROAD 原生恢复对比与 FAECO 独立在线闭环验证。

> **口径隔离声明**：SKY130（130 nm，10 电路）采用全芯片 15 轮详细重布线 + 全芯片 RCX 提取 + 传播时钟 STA 签核口径；ASAP7 `aes_cipher_top`（7 nm FF 多 Vt，20,097 实例）严格遵循 MLCAD26 官方后布局评估口径（`detailed_placement + global_route + estimate_parasitics -global_routing`，理想时钟）。两工艺节点面积与时序绝对百分比分表独立呈现，不跨工艺混算均值。

## 2. OpenROAD 原生功耗恢复负裕度开关证伪（`s382`）

在 `s382` `CONTROL` 起点（`BASE_WNS = -0.848457 ns`）实测：
- `repair_timing -recover_power 100 -slack_margin -1.0`：`Area +0.0%`，`Resized 0`，`WNS = -0.848457 ns`；
- `repair_timing -recover_power 100 -setup_margin -1.0 -allow_setup_violations`：`Area +0.0%`，`Resized 0`，`WNS = -0.848457 ns`。

结论：OpenROAD `26Q3` 的原生功耗/面积恢复引擎在遇到全局负 WNS 路径主导时，即使显式指定负目标裕度并允许违例，仍从算法层拒绝执行任何降尺寸替换。

## 4. Track B：ASAP7 7 nm `aes_cipher_top`（20,097 实例）跨工艺验证
