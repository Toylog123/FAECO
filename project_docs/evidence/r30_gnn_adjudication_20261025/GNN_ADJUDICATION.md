# GNN 编码器级裁决 — LOG-20261025-29

问题：LOG-20261024-24 建立了"门级图的**标量摘要**在候选级没有物理信号"，并声明该负结论**不能替 GNN 编码器背书**。本包正面回答这个问题。

## 1. 前置：图数据

- `extract_graphs.py --write-graphs` 此前**从未执行过** → 先沙箱预演（3 个跨电路候选，建图 → 序列化 → 回读校验节点/边数与悬空边，全过）→ 再全量。
- ITC-99 **1207 图 / 14.12 MB / 7 电路**（14–188 节点/图，87 441 节点、114 177 边）；ISCAS89 **339 图 / 6.33 MB**。
- 两次提取重跑与原文件 **SHA256 逐字节相同**（对照遍）。

## 2. 实现

- 环境无 torch/dgl/sklearn/scipy → **numpy 手写** 2 层消息传递 GNN，图按批补齐、传播为一次批量 matmul。
- **数值梯度校验**：mod 读出最大绝对误差 2.784e-11（相对 1.061e-05，30 项）；global 读出最大绝对误差 3.179e-11。
- 性能坑：`np.einsum` 不走 BLAS，比批量 `np.matmul` 慢 8–14 倍（数值一致）。
