## 3. 局部直连线网增量绕线加速与万门级 `b15` 端到端闭环

- **`b12`（7,978 µm²）局部增量对标**：仅清除受改 4 单元直连信号线网并执行 5 轮 DRT 耗时 **`52.94 s`**（对比全芯片擦除重布线 `112.02 s` 提速 **`2.12×`**），且 Setup 误差仅 `1.17 ps`、Hold 误差仅 `0.09 ps`。
- **`b15`（`33,737.36 µm²`、5,494 组件、4,373 线网、`UTIL=25%`）端到端闭环**：
  1. `CONTROL` 全芯片收敛布线耗时 `980.95 s`（`DRC=0`、`WNS = -15.8254 ns`、`hold = +0.4457 ns`）；
  2. 采用**联合 Setup+Hold 裕量 + 安全驱动排序 + 局部直连线网增量绕线（`render_local_incremental_flow_tcl`）**执行 6 轮搜索，**6/6 轮全部收敛至 `DRC = 0`**，单轮仅耗时 **`184.83–200.92 s`**（较同设计全芯片重布线 `1426.14 s` 提速 **`7.1×–7.7×`**，且全芯片 10 轮重布线仍残留 66 处 DRC）；
  3. 终选第 6 轮端点（`RUN_006`，提交 5 个高裕量门）在 **`184.83 s`、`DRC = 0`** 下实现：
     - 总面积净回收 **`88.84 µm²`（`-0.26%`）**；
     - **TT Setup `ΔWNS = +0.068 ps`（改善）**，**SS 慢角 Setup 改善 `+199.996 ps`**（$\text{SS }\Delta\text{hold}=0.000\text{ ps}$），**FF 快角 $\Delta\text{hold}=0.000\text{ ps}$**；

  4. 实测边界诚实说明：`b15` 在全芯片重新提取寄生下存在 `−0.021 ps` 的飞秒级数值底噪（绝对 hold 裕量 `+445.66 ps` 远大于零），故采用了 `0.05 ps` RCX 数值底噪容差以防飞秒级舍入假拒。
