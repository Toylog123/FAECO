# 三点曲线累计口径修正（LOG-20261025-27）

## 缺陷

`acceptance_evidence.metric_references.setup_wns` 是**迭代基线**网表的理想 WNS，不是电路基线的。
训练表的 `ideal_cumulative_wns`（= `ideal_wns - ideal_baseline_wns`）因此就是**边际量**，
而 placed / routed 的累计列确实是相对电路基线的 → 该块三档混用口径。
ISCAS89 侧因此给出"物理阶段与理想阶段负相关"（rho = -0.1125 /
-0.1251），物理上不可能。

## 判决证据

1. ledger 直读：iteration-1 trials 的 `base_netlist_hash` = 电路基线网表哈希、其参照值即电路基线理想 WNS；
   iteration>=2 trials 的参照值 = 上一轮被接受候选的 `setup_wns`。
2. 数据集统计：每电路 `ideal_baseline_wns` 有 2-7 个不同值且随迭代变化；
   2218 个可比行里 1630 行匹配迭代基线、
   0 行匹配电路基线。
3. 重算一致性：用迭代基线重算 `ideal_delta_wns`，1630 行中
   0 行不同。

## 边界

探针级、非论文证据；理想档的电路基线取自 ledger 的 iteration-1 参照值，与物理档的 OpenROAD
实测基线 WNS 不是同一来源（各自相对自身基线可比，绝对值不可互比）；寄生来自
`estimate_parasitics`、非签核 RC 提取；累计口径下"电路基线"与"迭代基线"两套参照同时存在，
引用时必须写明用的哪一套。

## 符号翻转的严格口径（本条的后续更正）

工具口径的"符号不一致"是 237/1161 = 20.41%，但它的判据 `(x > 0) == (y > 0)` **把零也算作不一致**。严格口径：

| 类别 | 计数 |
|---|---|
| 理想说改善、物理说退化 | 14 |
| 理想说退化、物理说改善 | 81 |
| **严格反号合计** | **95（8.18%）** |
| 含零的不一致 | 142 |
| 同号且都非零 | 593 |
| 理想读数为 0 | 298 |
| 布线后读数为 0 | 56 |
| 两者都为 0 | 119 |

两个方向很不对称（81 : 14 ≈ 5.8 : 1）：**物理档比理想线网更乐观的次数远多于反方向**，与修正后累计读数（布线后累计 mean 高于理想累计 mean）同向 → **理想线网的问题不是"过度乐观"，而是"加了方向噪声"**。

## 「理想线网说谎」的最终形状（自审后定稿）

**「理想线网说谎」的准确形状不是「方向说反」，也不是「幅度虚高」，而是「改善幅度落在物理噪声以下、不可分辨」**：① **幅度不失真**——理想→布线后的斜率 0.9572 ≈ 1，修正后的**累计**口径下斜率 1.2057 > 1、理想线网对多轮 ECO 净效果的预测 ρ = 0.8769 / 0.9461；② **方向也不是主要失效点**——全体 1161 个候选里**严格反号只有 95 例 = 8.18%**（含零的不一致 142 例、同号同非零 593 例），44 个接受决策的纯符号方向一致率 68.18%，且**理想线网整体偏保守**（"理想说增益而物理没增益" 10 例 > "理想说退化而物理改善" 4 例），带口径下被物理确认为**真实退化**的只有 3/44 = 6.82%；③ **真正的失效在可分辨性**——44 个接受决策里 **37/44 = 84.09%** 的理想增益**低于布线后判定带 0.049752 ns**（带内 30/44 = 68.18% 无法判定），且 **15/44 = 34.09%** 的理想增益**恰好为 0.00**（理想线网下 WNS 根本没变，其中 5 个布线后也是 0.00；**为何这些动作仍被接受待查**——FAECO 的接受判据是否含 WNS 之外的指标）。 → **因此"理想线网说谎"必须改述为"它给出的改善大多落在物理噪声以下（84.09% 低于判定带），而不是方向说反或幅度虚高"**；这个形状对论文的直接影响是：**不能用"接受候选的 WNS 改善"作结论**，要用"在接受候选中避免了多少可分辨的真实退化 + 有多少真实增益能被物理确认"。
