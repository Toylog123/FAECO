## 规约

沿用原 UART 的 CONTROL、270 ps 周期、54 ps I/O、三视图、18 个冻结候选及同一顺序、在线诊断、保护范围、独立全块 DRC、天线、电气与 SEC。每臂计入同一份 81.563830427 RAW s 筛选成本，最多 720 RAW s 和六次实际物理评价。各视图 setup WNS 损失限为 2.7 ps，FF／TT／SS 的 TNS 损失限为 27／27／136.9736502 ps，hold 保留绝对非负及相对不退化门。面积目标为参考功能单元面积的 0.01%，即 0.007900902 µm²。按原版、去重、去重、原版串行运行，不复用不同臂之间的物理测量。固定批次的参照是原六臂中两序均达到的 0.23328 µm²。

去重仅识别本臂已经以同一冻结起点完成 DRT、RCX、三角 STA 和独立 DRC，且仅因 setup WNS 或 TNS 超预算被拒的完全相同累计动作。命中后沿二分路径继续，保留六次实际评价。尝试过的其他动作、物理阶段失败及 hold 拒收均按原规则处理。实验显示的跳过次数来自独立收据，不与验证工具的实际调用数相加。

离线重放预测，去掉一次重复后，新增第六个物理评估为 `_0703_`、`_0814_`、`_1027_`，预测功能面积回收为 0.20412 µm²，低于固定批次的 0.23328 µm²。实际是否增加回收取决于该组合的完整物理验收。
