## 1. 复算范围

数据来自旧稿 PDF/DOCX 的表1和表2。对每个 Industry case 使用下式从表中显示的 before/after slack 反算改善比例：

```text
improvement(%) = (before - after) / before * 100
```

旧稿未保留原始高精度时序日志。以下结果只能核验稿件内部一致性，不能恢复原实验的权威统计值。

## 4. 审计结论

1. B&G 正文的 55.02%/60.5% 与表2及两种复算均明显不一致。
2. 表2 Avg 行也不是逐 case `Inpro(%)` 表示值的直接算术平均；RSECO 的 88.16%/90.49% 同样不能由显示行直接复现。
3. 显示 slack 只有两位小数，无法恢复原始高精度数据；因此不能据此指定唯一“修正后的旧实验均值”。
4. FAECO 新论文不得把上述旧均值作为主结果。若历史结果必须保留，应逐 case 展示并明确标记为不可复现实验观察。
