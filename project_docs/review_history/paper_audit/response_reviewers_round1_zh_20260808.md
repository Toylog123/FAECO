## 二、结构问题

### 1. 摘要信息过载（已修改）
摘要重构为四层：背景问题（2 句）→ 核心方法（1 句，三阶段明确为'先…再…最后…'）→ 关键创新（1 句，两点并列）→ 主要结果（2 句，只保留代表性数据 8/8、18/19、2/3、s382 WNS、1.07 ns）。原摘要中的'超大违例锥分治''候选 STA 调用削减 75%'等技术细节移出摘要，正文保留。

### 2. 引言头重脚轻（已修改）
'背景与问题'扩充了完整问题陈述：先说明传统 B/G 的局限，再交代补丁替换范式的不可复现困境，新增一段论述'等价性检查与物理时序优化串行独立 → 候选空间割裂 → 等价失败与时序收益不足互为因果 → FAECO 统一处理'的动机链，使贡献部分与动机自然衔接。

### 3. 方法章节组织（已修改）
方法节重排为四小节：3.1 问题形式化（ECO 修复问题定义 + 术语约定 + 输入 + 符号表，紧接引言之后）→ 3.2 方法框架总览（三阶段流水线 + 算法 1）→ 3.3 核心机制（按'双目标联合割与节点代价 / 失败感知细化 / 两环闭环与内环决策层 / 形式等价与 SPEF 门控'拆为 4 个子节）→ 3.4 工程实现要点。符号表已从方法总览与核心机制之间移至 3.1 紧后位置，符合审稿人建议的渐进理解顺序。

### 4. 实验部分结构松散（已修改）
实验部分重排为七个子节，逻辑递进为主结果 → 泛化 → 消融 → 基线对比 → 物理验证 → 补充：A. 实验设置（原'工具链与环境/数据集/参数与可重复性'三段升级为正式子节）→ B. 主结果：ISCAS89 → C. 跨基准泛化验证：ITC-99 与 PicoRV32（原两个子节合并）→ D. 消融：失败感知反馈与决策层 → E. 对比：收敛配置基线（混合 vs 单一策略/随机）→ F. 物理验证：版图保持性与 SPEF 门控 → G. 补充：Hold。每节开头增加'本节回答什么问题'引导句，消融与基线对比两节末尾增加小结句，明确二者互补关系（前者回答同候选空间下排序与反馈的贡献，后者回答混合空间相对单一策略的贡献），消除'内容重叠'观感。

### 5. 结论过短且与摘要重复（已修改）
结论重写为两段：第一段给出总结性判断（FAECO 的本质贡献：从'先割后验、事后丢弃'变为'构造即筛选、失败即反馈'），不再复述设计细节；第二段以一句代表性证据（约 6% 实测开销达到纯 G 同等质量）支撑判断后直接给出方向性局限 3 条（版图感知闭环与参数校准、更大搜索空间的效率边界、库约束下的失效边界），删除原与摘要重复的 1.07 ns、5/8 等数据罗列。

## 三、语言与表达问题

### 1. '的'字冗余与欧化句式（已修改）
摘要例句改为'本文提出 FAECO——一种面向预布局逻辑重综合的失败感知候选生成引擎'；'把等价性约束前置为割图软约束……降低……互斥发生率'改为'将等价性约束作为割图软约束前置……降低等价失败与时序收益不足之间的互斥'。正文对'把/将'字句做了统一清理：方法总览、核心机制、失败感知细化、工程实现要点、消融与 ITC-99 等 10 余处'把'改为'将'或改写为主动/无标记句式，保留符号表内'把 S 与 T 分开'等必要表达。

### 2. 术语使用前后不一（已修改）
在 3.1 问题形式化中新增术语约定：'本文所称重综合即逻辑重综合；割指以节点权重为依据将违例锥划分为保留与替换两部分的操作，割解为该操作的输出'；标题保留'逻辑重综合'，正文统一使用'重综合'并在术语表中说明。'候选'在三类语义（候选补丁/候选门/候选策略）处均以 $mathrm{patch}$、'候选门'、'候选类型'明确区分。

### 3. 标点符号（已修改）
全文统一中文标点；修正英文缩写与中文标点间的多余空格（如'12,800,135 bytes，SHA256'）；数学公式、英文与中文之间保留半角空格；正文引用一律使用 \cite 格式。

### 4. 长句过多（已修改）
摘要三阶段句改为'先进行重综合与技术映射，再执行双目标联合割与候选生成，最后以简化 SPEF 门控完成验证'；方法总览 (b) 末句拆分为两句；核心机制 s-t 分裂图句拆为两句；ITC-99 b06 长段在失效边界句后分段，策略分布另起一段。

### 5. 口语化措辞（已修改）
'兜底'3 处全部替换为'由 ABC CEC 提供最终等价性保证 / CEC 最终保证'；摘要中'8/8 改善、18/19、2/3、5/8'改为'8 个电路全部改善、19 个电路中的 18 个、3 个异构子模块中的 2 个、5 个电路'（实验部分保留 8/8 等简写，属实验段落常规表达）。
