## 3 主张为什么是"收益来自覆盖"

W1 在 8/8 电路为正、合计 1.29 ns；**节点加权（W0/U0）零改善且几乎不评估**、**EMA 反馈 8/8 逐位相同**、
**扩覆盖同预算增量 0.0000**、**JOINT / pin swap 零点变化**。⇒ 涨的是"被覆盖到的可动门"，不是排序、不是预算、不是规模。

而这个覆盖**原本漏了一整类动作**：触发器。补上之后上限从 1.29 抬到 1.68 ns（+30.2%），
且增益在真实寄生下被放大。**论文现在的写法是**：动作集**完备性**（不是"动作空间已穷尽"），
并明确写出剩下两个障碍（补丁比例上限、TNS 退化规则）挡掉了 s27/s420 与 s641/s713。

1. **编译用 lualatex**，且两篇各编译两遍；换引擎会得到字节不同的 PDF。
2. **行尾**：`.tex` 与 `OPEN_ISSUES.md` 纯 LF、`LOGS.md` CRLF、`*.sh` LF（由 `.gitattributes` 强制）。`write_text` 会静默把 LF 翻成 CRLF，改完要字节复核。
3. **`sta` 必须带 `-no_splash -exit`**，否则挂住等 stdin（表现为"跑不完"）。
4. **物理流程**：`detailed_route` 必须给 `-droute_end_iter`；布线后 STA 必须读 `<top>.routed.v` + SPEF，否则读的是布局后网表。
