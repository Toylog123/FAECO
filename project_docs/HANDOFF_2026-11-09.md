## 6 最容易踩的坑（其余见 `CANON.md` §10）

1. **编译用 lualatex**，从 `paper/zh/manuscript/` 目录直接跑，两遍；**不要用 `compile.ps1`**（`build/` 下 `./fonts/` 解析失败）。
2. **行尾**：`.tex` 与 `OPEN_ISSUES.md` 纯 LF、`LOGS.md` 工作区 CRLF（HEAD blob 却是 LF，提交需 `git -c core.autocrlf=input add`）、`*.sh` LF（`.gitattributes` 强制）。`write_text` 会静默翻 LF→CRLF，改完要字节复核。
3. **`sta` 必须带 `-no_splash -exit`**，否则挂住等 stdin。
4. **物理流程**：`detailed_route` 必须给 `-droute_end_iter`；布线后 STA 必须读 `<top>.routed.v` + SPEF。
5. **`git add -A` 禁用**（行尾假象会混进提交），按路径逐条 add。
6. **补充 tex 的 `edit` 坑**：`edit` 会重写整份文件的行尾；改 S4.6 这类大块后要用 `git show HEAD:<file>` 恢复原始混合行尾，否则 diff 会从 32/9 膨胀到 833/810。
7. **物理档工具链**：`estimate_parasitics -placement` **必须**先 `set_wire_rc -layer met2 -signal` / `-layer met4 -clock`，否则它静默不生效（候选与理想档逐位相同）；布线后 STA **必须**用独立 `sta`（openroad 的 STA 模式缺 LEF，报 `ORD-2010`）；`detailed_route` 必须给 `-droute_end_iter`。
8. **成本读数必须先固定 `--workers`**：同一配置下 workers 1→4 会让候选 STA 次数从 97 变 212（缓存命中与在途候选数变了），**成本只在同 workers 的臂间可比**（`experiments/20261110_placed_gate/PREREGISTRATION.md` §7-A1）。
