- **禁 `git add -A`**（行尾假象会混进提交），按路径逐条 add。HEAD 一律以 `git log -1` 为准，本文件不记哈希（记了就必过期）。
- **本目录下 `os.remove` 会重定向进 Windows 回收站** ⇒ 删完须清 `D:\$Recycle.Bin`，否则磁盘不释放；被其它进程占用的目录连 `mv` 都会 Permission denied。
