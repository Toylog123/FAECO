## 5. 未决与风险

1. **扩面只有 F0 一个布线实现 → "实现效应"类分析在扩面池上测不了。**
   实查作业表轴：`jobs_itc99_ext.tsv` 全部为 `util=10 / F0 / pin_hor=met3 / pin_ver=met2 / core_space=2`，与既有 `jobs_itc99.tsv`（同轴）完全一致；F1 是 `util=30 / met5 / met4`、F2 是 `met3 / met4`，**扩面表里都没有**。后果：扩面**不能**用来扩 F0/F1 带、不能做留一实现比较、不能声称"实现效应在更多电路上也成立"。
2. **判定带的样本作用域是数据属性，扩面接进来会改变带门槛数字。**
   `select_scope()` 按**实际覆盖度**在 `full_family` / `pilot_subset` 间选，审计与测量共用同一函数，作用域写进 `band_scope.json`。扩面 6 个电路进来后，覆盖度、df、逐电路离散度都会变 → **所有以带为门槛的数字都要重算**，且必须**像 LOG-20261024-23 那样明确标注口径变化**（带值、作用域、df、网表数、电路数四件套一起报）。
3. **b14 仍未定论。** 见 §1.1：**三个运行**（档案 `b14_baseline` 有 38493 条路径报告 / 档案 `b14_fixed` 0 条 / 探针 `b14_baseline_R0` 0 条）结论不一致，**必须单独串行重测**才能定；在此之前既不计入可达、也不计入不可达（这与"未跑完 ≠ 不可达"是同一条纪律）。
4. **`scratch/verify_round_35.py` 崩溃（LOG-20261025-37 的终检，不是扩面批的终检）。**
   第 137 行 `forms.add('%.' + str(nd) + 'f' % x)` —— Python 先算 `'f' % x` → `TypeError: not all arguments converted during string formatting`，脚本在 **D 段（反幻觉数字回溯）入口即死**，**D/E/F 三段从未执行**。实测：崩溃前 **A/B/C 三段 16 项全 OK、0 FAIL**（A1–A5 / B1–B8 / C1–C3），但"LOG 行里每个数字都能在 D 证据里找到"这一门**目前没有跑通**。接手者要么修这一行的运算符优先级，要么另写一个终检——**不要把"16 项通过"当成该终检已通过**。
