## 5. 本轮沉淀的方法论

1. **文献表改动后必须重跑编号顺序探针**：机械的"bibitem↔cite 一一对应"检查**不覆盖编号是否按引用顺序**；本轮 P0 即由此漏出。
2. **Word 转排管线有硬编码文献计数守卫**：`preprocess.py` 的 `N_BIB` 必须随文献条数同步改，否则守卫死循环/失败。
3. **摘要（及任何被管线硬编码的段落）改写须同步两处**：`.tex` 与 `scratch/word_convert/postprocess.py` 里的 `zh_abs`/`en_abs`（后者为**硬编码**，非从 `.tex` 读取）。
4. **`\footnote{\url{…}}` 经 pandoc 自动转 Word 原生脚注**（写 `word/footnotes.xml` + `w:footnoteReference`），无需自定义处理。
5. **PDF 字节 SHA ≠ 内容指纹**（沿用）；**附注标签取提交须 `<tag>^{commit}`**。
