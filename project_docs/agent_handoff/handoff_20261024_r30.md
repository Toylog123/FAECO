## 6. 边界与不得外推

- 寄生来自 `estimate_parasitics -global_routing`，**不是**布线后 RC 提取的签核口径；
- 代理模型原型为**探针**，负面结果支持"EMA 无额外收益"的观察，但**不得**断言"代理模型永远无用"；
- 判定不稳健只能读成"**单实现不足以判定退化**"，**不是**"物理后收益更大"；
- 校准图**只作预览**，不入主稿、不替换任何论文图；
- 本轮**不改 `code/`、不提交**；四 partial / D 正式 28/56 与 raw 3/8 / OI051 等科学门不因本轮变动，
  物理闭环排在 D 门之后；
- 未跑完的批次**不得**当作"该电路无物理标签"。
- **结构特征与代理模型均为探针级**：特征是**手工标量图摘要**，**不是 GNN**，
  "图里无信号"只对这些摘要成立，**不得**外推为"神经网络不可行"；
- ITC-99 的结构与拓扑结论出自**部分标注族**（布线后标签仍在补），批次收齐后由定稿链重算；
- 拓扑"偏好消失"的两个口径之差**未做正式检验**，且布线后标签噪声受限，
  只能读成"与虚假繁荣一致"，**不是**证明；
- 结构改动量与候选**类别纠缠**（插 buffer 按定义就加单元），本测量**无法完全分离**二者。
- **决策遗憾下界是蒙特卡洛估计**：把观测标签当真值再叠加合成噪声，σ 取判定带/2；
  而 44 个真实配对给出的经验 σ 只有判定带/2 的 0.55 倍 → **带偏保守、下界偏悲观**，
  两组数都列出，不单取一个。
- 真实双实现配对目前**每个池只有 1 个候选**有两次测量，**池内"平均两次测量"的比较尚不可做**，
  须等 I1 / F1 批覆盖全族（这正是正在跑的批次）。
