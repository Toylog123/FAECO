# FAECO r20 学术叙事收敛方案（narrative convergence）

日期：2026-10-13　｜　前置基线：**v17**（r19，提交 `40eb8b8`）
触发：用户对**作者版(7) = v17** 的第五轮通读意见。用户判断：

> **这一版的整体框架已经基本正确，主线比之前清晰很多。但距离高质量 EDA 论文还有一个关键提升空间：需要进一步强化「候选探索」作为唯一主线，让加权割、R/G/B/JOINT、失效刻画、验证流程都成为围绕这个主线服务的组成部分。**
> 这版已经不是「需要重构」，而是「需要最后一次学术叙事收敛」。下一步重点不是加内容，而是**让所有章节都回答同一个问题：如何在有限验证预算下进行有效的预布局 ECO 候选探索。**

用户给出的 5 处修改按重要性：**P0① 明确唯一主线（摘要 + 引言）→ P0② 降低第三贡献权重 → P1③ 失效反馈语言进一步弱化 → P1④ 实验章节标题围绕 candidate exploration（尤其 4.5）→ P2⑤ 结论强化意义**。

## 0. 定位结论（本轮主线）

- **唯一核心**：*Candidate exploration under limited verification budget*（有限验证预算下的候选探索）。
- **各模块的从属角色**（用户给定表）：

| 模块 | 角色 |
|---|---|
| weighted cut | 扩大候选空间的方法 |
| $C_c$ | 提高关键路径覆盖的方法 |
| R/G/B/JOINT | 候选类型 |
| ranking | 降低搜索成本 |
| F1–F6 | 理解搜索失败 |
| SEC / SPEF | 保证候选可靠性 |

- **贡献层级**：2 条贡献（核心 + 辅助）+ 1 个**实验基础平台**（不再作为并列贡献）。
