## 建议的 FAECO 口径

### 面积是收益，时序限定质量

1. 从每个电路同一份已详细布线、已提取寄生的 CONTROL 出发，保持原始 SDC、时钟周期和 I/O。对三种策略使用相同候选集合、目标场景、物理评估器和交付门。物理候选重新完成 DRT、RCX、三视图 STA，所报端点通过全网表 SEC。
2. 面积以经核验的功能标准单元 Liberty 面积和为准。回收量为 CONTROL 面积减去最终端点面积，百分比以该 CONTROL 为分母。共同起点修复增加的缓冲面积和耗时单列。功耗有同口径可信数据时可作辅助结果。
3. 每个 FF、TT、SS 端点并列给出 setup WNS、TNS 的绝对量及相对起点变化，另给出最差 hold、新增 setup 违例端点数及其 view。WNS 告诉我们最差端点退化多少，TNS 和端点计数能揭示 WNS 几乎不变时其他路径的负担。保留 DRC、电气有效性和功能等价记录。
4. 最终时序包络可以允许非零 setup 损失。建议预先决定每个视图可承受的最终 WNS/TNS 损失和绝对下限，再让三臂共用。至少明确原先非负的视图是否允许跨零、已经负 slack 的视图允许恶化多少，以及 TNS 只作诊断还是也作交付约束。若同时展示多个损失档，0 ps 可作保守参照。跨工艺图可加报 WNS 损失占原周期的比例。档位须在留出评测前冻结。
5. 搜索参数与最终交付包络分别定义。将来如果试验允许暂时超预算再修复，应将修复后的面积、时序和全部成本计入同一策略，并把该变体与现有 FAECO 分开标识。

### 两个配对比较

| 比较 | 输出 | 读数规则 |
|---|---|---|
| 同一最终时序包络、同一实测墙钟预算 | 截止时刻前经过全部验收的最佳回收面积 | 每档画时间到已验证面积的阶梯曲线，CONTROL 为起始零回收。尚未完成验证的物理端点在完成时才进入曲线。 |
| 同一最终时序包络、同一面积目标 | 第一次得到已验证端点的墙钟时间 | 面积目标预先确定。预算内未达到的策略按未达到报告。配套报告 DRT、RCX、STA、SEC 次数，解释时间由何而来。 |

所有策略从同样就绪的 CONTROL 开始，以完成端点验收为计时边界。共同起点构建、hold 修复、预热和零动作校验分开计费。共同候选池的构建列入共享准备，策略专属的排序和调度计入该策略。报告同机器线程、运行顺序、并行负载和各阶段时间。对同一时间预算或面积目标下的速度结论，先做独立重复实跑。在诊断中复用完全相同的物理候选时，账本要区分实际工具调用、逻辑评估次数与估计计费时间。等调用次数可作为附表。

## 用现有 ASAP7 数据检验这个口径

旧实验使用每视图 10 ps 相对 setup 损失预算。单门贪心和 FAECO 第三次都得到同样的两个换门，ODB、DEF 和网表字节相同，SPEF 仅时间戳不同，三视图时序一致。两者均回收 0.26244，约为起点功能单元面积的 0.012322%。共同端点 FF setup WNS 从 +0.380362 ps 变为 −4.379830 ps，FF TNS 从 0 变为 −37.870485 ps。TT、SS setup WNS 分别损失 2.049250 ps、0.536016 ps。这个端点在旧包络下被接受。若将已达标视图的非负 setup 写成交付门，它会失败。 [原起点](../evidence/tcad_ibex_20261123/asap7_control/CONTROL.json) · [候选与核验](../evidence/tcad_ibex_20261123/ASAP7_P1_VERIFIED.json)

## 从文献口径到 Ibex 开发试验

- 主表用**等时序包络与等墙钟预算的面积回收**。第二张图用同一包络下的时序与面积前沿，或同一面积目标的验证完成时间。每个点都可以回查端点与所用时间。
- Ibex 主比较采用 1% 原周期的逐视图相对 WNS 损失限，TNS 损失限为 WNS 损失限的十倍与同一百分比的起点绝对 TNS 取大者。另以 0%、0.5%、1% 对照是否保护起点 setup 非负的视图。共同墙钟窗按工艺固定为 1200 s、720 s，共同面积目标均为各自 CONTROL 的 0.01%。这些是本轮 Ibex 的试验参数，新设计留出确认另行冻结。[实验登记](../evidence/EXPERIMENT_REGISTRY.md#2026-11-23-tcad-ibex-p1-setup-protocol-v1)
- 两套 Ibex 已有数据适合做开发期计量样例。尤其是 SKY130 共同修复起点 SS setup 仍为 −38.757 ns，旧单门候选的 TT setup 损失为 377.550–763.920 ps。将其与其它时序裕量更接近目标的设计分别呈现，有助于判断面积机会和比较规则各自的影响。 [SKY130 起点与诊断](../evidence/tcad_ibex_20261123/REPORT.md)
