# 物理档效果只报「四数」，不报同网表前后差

> 立：2026-10-29。适用族：`20261029_eco_phys_samelayout`（ISCAS 八例）、
> `20261029_itc99_eco_fournum`（ITC'99 六例）。

## 0 · 问题

此前 ITC'99 六例表报的是

```
ΔWNS = 布线后 WNS(同一网表) − 理想档 WNS(同一网表)
```

这个量只说明「布线寄生把 WNS 拉低多少」，与 ECO 有没有效果无关：一份完全没有改善的
网表，这个差同样成立。用它回答「我们的方法在物理档还剩多少收益」是错的。

## 1 · 正确比法（四数）

```
                预布局(ideal)   布线后(post)
基线 base            A                B
ECO 网表             C                D

预布局档改善  = C − A
布线后档改善  = D − B
保持率        = (D − B) / (C − A)
```

三条硬规则：

1. **A 与 B 必须来自同一次 base 运行**，C 与 D 来自同一次 ECO 运行；
   两臂除「换门」外，布局与流程条件尽量一致（同布局族用同一份 CTS 前种子）。
2. **D − C（同网表布线前后）不入表、不作效果口径**，只可作为寄生惩罚的背景量。
3. 保持率分母 ≤ 判定带（0.049752 ns）或分子在带内时**不可引用**。

## 2 · 两族怎么落地

**ISCAS'89 八例**：三臂 `base` / `eco` / `ecofix`，ECO 网表来自 hybrid repair 推荐
（换 1~5 个门）。四数已齐，见该族 `REPORT.md` §4。

**ITC'99 六例**：原只有 base 一份网表，没有 C 与 D。补法是
`code/scripts/gen_itc_eco.py`：

- 在**理想档**取关键路径，对路径上的组合门按同功能族升 drive strength；
- **每个候选实测一次 STA**，只接受严格改善 WNS 的那一个，最多接受 5 个门；
- 输出 `mapped.v`（结构不动、只换 master）+ `swap.tsv`。

与 hybrid repair 的差异必须在报告里写明：**只做 G（升档），不做 R（等价重写）与 B（插缓冲）**。
因此 ITC'99 的 C−A 不能当作「我们的方法在 ITC'99 上的效果」，它只是让四数成立所需的那一改。

## 3 · 可比边界

- **方向可比**：同一族内，C−A>0 是否兑现成 D−B>0。
- **幅度不可跨族**：ITC'99 关键路径由映射后高扇出（fanout 29~71、单级 2.0~8.3 ns）主导，
  ISCAS 最差两例 fanout 仅 7/17、单级 ≤0.66 ns；根因是 `synth -flatten` 未做 `repair_design`。
  两族的 C−A、D−B 绝对值**不得并列比较**，只能说方向是否一致。
- **噪声底**：同网表同命令重跑一整套布局+布线，|ΔWNS| ≤0.03 ns（n=8，中位 0.01）。
  任何小于 0.05 ns 的差都要先与该底线对照。

## 4 · 禁令

- 不得用 D−C 代替 D−B；
- 不得用「理想档改善 × 保持率」推算物理档改善（保持率正是待测量）；
- 不得在 ITC'99 与 ISCAS 之间拼表或引单个数值；
- b15 的高扇出异常单列，不并入均值。
