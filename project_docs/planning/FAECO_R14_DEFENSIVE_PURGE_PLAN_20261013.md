## 一、判据（本轮的唯一取舍标准）

对每一处候选，问三个问题；**三者皆为"是"才改**：
1. 它是否在**预先回答一个假想的质疑**（而非陈述事实/结果/范围）？
2. 删改后，**信息是否已被别处覆盖**（表注 / 实验节 / 首次定义）？
3. 它是否**不是审稿人（r12）指定的落点**、也非既有裁定（OI-014 / OI-015 / r6 P0）的载体？

> 反例（必须保留）：`该约束不代表…` 类**范围定义**只保留一次（首次定义），但由 r12 审稿人指定的**口径表注**（M1/M2/M3）与负责"不夸大"的**负结果陈述**（NEGATIVE finding）一律保留——它们不是防御性限定语，而是**证据本身**。
