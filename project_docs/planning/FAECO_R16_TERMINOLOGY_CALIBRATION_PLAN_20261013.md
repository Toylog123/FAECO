## 3. E17（§5 结论）细则与保留冲突的处理 ★

**用户 §十要求**：删 PicoRV32 解释（`（PicoRV32 第三个子模块无 setup 路径，不计入分母）`）+ 减少实验细节。

**冲突**：`保留清单`（r14/r15 确立）载明 **PicoRV32 分母说明 5 处**是 **r12 M2（★★★★）** 的指定落点，理由是 **`2/2` 若不带分母说明会被读作"抹去一个实例"**。结论的这句即 5 处之一。若按字面仅删括号而保留 `2/2`，会**违反 r12 M2 的必要覆盖**。

**处理**：**删整个逐测试集三元组**（`在 ISCAS89、ITC-99 和 PicoRV32 测试集上，分别有 8/8、18/19 和 2/2 个实例取得严格 WNS 改善（…）`），使结论**不再出现 `2/2`**，从而既满足用户"删 PicoRV32 解释 + 减少实验细节"，又不留下任何"无分母说明的 2/2"。

- 三元组已在**摘要 / §1.3 贡献 3 / §4.3** 三处出现，结论不复述符合"结论不复述实验细节"的一般要求。
- 结论保留 headline：`1.07 ns` vs `0.16 ns`（固定权重配置）+ 候选排序减少首次改善所需候选级 STA 次数。

**改写**：
- 原：`…在 ISCAS89、ITC-99 和 PicoRV32 测试集上，分别有 8/8、18/19 和 2/2 个实例取得严格 WNS 改善（PicoRV32 第三个子模块无 setup 路径，不计入分母）。在固定权重、20 轮迭代实验中，混合候选策略的平均 WNS 改善为 1.07\,ns，高于纯 G 策略的 0.16\,ns；随机排序实验进一步表明，候选排序在多数电路上减少了取得首次改善所需的候选级 STA 次数。`
- 新：`…在固定权重配置下，混合候选策略的平均 WNS 改善为 1.07\,ns，高于纯 G 策略的 0.16\,ns；跨测试集评估与随机排序实验进一步表明，候选排序在多数电路上减少了取得首次改善所需的候选级 STA 次数。`

> **若用户希望结论保留三元组**：回退本项即可（一行），改为保留原样（含分母说明）。**不提供"保留 2/2 但删括号"的中间态**——那会破 r12 M2。
