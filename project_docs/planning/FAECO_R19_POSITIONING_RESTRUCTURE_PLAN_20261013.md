## 0. 定位结论（本轮主线）

- **核心问题**：`现有预布局门级时序 ECO 方法受候选类型单一与候选评估成本高的共同限制。`
- **方法定位**：FAECO = 一个 **candidate exploration framework**（而非「一种加权割」）。
- **贡献层级**（由三个平行贡献 → 一个核心问题 + 三个支撑块）：
  - 核心问题：**预布局 ECO 中的候选探索**（布局信息缺失 + 候选验证昂贵下，如何扩大局部修改搜索空间并有效安排评估顺序）
  - 支撑 ①（主）候选空间扩展：$C_w$ + $C_c$ → R/G/B/JOINT
  - 支撑 ② 候选优先级：cost(v) + 路径覆盖 + 策略优先级
  - 支撑 ③ 搜索分析：F1–F6（**框架的组成部分**，非独立模块）
