# FAECO 后布线定向面积回收实验路线

2026-11-24。建议按 6 周执行，预留第 7–8 周给起点制备、工具差异和无法复现的案例。当前可做方法与论文框架收口，并行制备新起点。论文的跨设计优势、统一评测和投稿结论仍须依下面各阶段实测。本路线由现有证据出发，不改变既有数据、归档或已验收端点的资格。

## 主问题与共同规约

论文检验两个问题。给定已布线设计、真实时序预算和有限验证时间，面向邻线冲突的在线诊断能否减少无效物理验证？自适应调度能否将预算转化为更多合格面积？ECO 以候选动作和局部物理冲突为修复对象，独立设计验证检验自动机制在新对象上的适用范围。

1. **起点与最终门。** 同设计各方法共用冻结 CONTROL、候选池、原周期和完整原 SDC／I/O、相同工具和 RCX。主档先沿最近已实跑的逐视图 1% 原周期 setup WNS 限和既有 TNS 规则，留出前固定实际数值、单位及对起点非负 setup 视图的政策。保持各视图绝对 hold 非负及相对原起点非退化、原电气、独立全块 DRC 和天线、非空 SEC。需共用 hold 修复时先独立证实和冻结，保存原几何、修复代价及失败的资格案例。IO+OCV 若有完整、绑定的约束和工艺实现，建立独立登记的压力档。历史 s713／s832 绝对 hold 负例继续在压力档保留。
2. **计时。** 已有配置从 SKY130HD 720 s、ASAP7 1200 s 起步，顶多 6 个逻辑请求。新设计按资格阶段测得的工具可运行性，在读取任何方法结果前锁定各设计的共同墙钟与逻辑上限。两种限制分别记录触发原因。共同筛选和方法专属诊断、搜索、失败重试、恢复全块检查与 SEC 都入账。准备合格 CONTROL 的成本独立列。任何窗尾超时的 DRT／STA／DRC／SEC 保留原件，完成全部验收后才进入收益曲线。事后补审留单独一列。
3. **主指标。** 主表给固定硬窗的合格面积减量、相对 CONTROL 的百分比和逐电路绝对量。配对图给相同 0.01% 面积目标的首达时间与每个已验收端点的时间阶梯，标出未达标。可提前登记一个更高的共同面积目标作为附表。每个端点同时给 FF／TT／SS 的 WNS、TNS、最差 hold、新增负 setup 端点数。统计 DRT/RCX、诊断、STA、DRC、SEC 的启动、完成、时长与失败原因。等物理调用次数和具有统一估算口径的功耗可放附表。百分比改善和运行时间按设计配对报告，重复运行衡量同设计波动。
4. **组别。** 机制对照为固定／FAECO × 常规后端／在线诊断后端，共四臂。另加一条与完整 FAECO 共用在线后端的调优单门贪心。原生 OpenROAD 回收按相同可比输入和门运行作外部参考，单独说明它实际可用的候选和计时范围。关键分项由同后端、同调度的配对读数判断，完整方法以强基线和主指标验证。
5. **重复与完整性。** 同机固定 CPU 组与线程，每个主矩阵做两轮，第二轮逆序，运行时不并发另一个主计时实验。原始计时使用配对统一单调钟，记录宿主时钟校验和负载。与运行波动同数量级的差异标为无稳定时间优势。报告单位是独立设计或设计家族，候选和重复运行保留配对关系。所有收益为零、超时或初始资格失败的案例保留。

## 判断整体完善的条件

- **可以现在收口。** 明确输入、候选生成、局部 DRC 反馈、受预算调度、全物理验收和输出指标，整理成可运行的统一流程。现在可开始写问题、方法、规约和 AES 机制案例。补出同后端强基线前，论文可把现有性能数字按已实测的设计和运行顺序准确陈述。
- **期望证明诊断机制。** 开发期同动作对照中应能复查省下的真实物理验证，诊断计入后仍有净收益，且保持同等验收质量。若在多个新设计上常遇无标记或不可映射标记且诊断费用反超，保留失败结果并把适用条件写清。
- **期望证明调度机制。** 新设计上在等时间和等时序条件下展示合格面积和共同目标首达的配对净收益。若仅 AES 改善，或在线固定／单门在大部分留出设计持平或更优，收窄调度主张并分析哪些布局状态可受益。若只有 SKY130HD 达到完整物理与约束资格，工艺范围按实际限定。
- **可开始投前判断。** 至少完成上表主矩阵、可复现核验、预算敏感性与失败记录、和最强近邻的贡献定位，再决定 TCAD 稿件主张。当前优先比较“固定与 FAECO 各自在同一个后端的表现”，同时开展留出 CONTROL 预检。固定的算法参数都在留出开跑前登记。
