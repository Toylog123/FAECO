# 周报（weekly）

> 周期性总结（每周 / 双周 / 里程碑）。每个周期产出当周 `2026-W##.md` 一份。

- `WEEKLY_TEMPLATE.md`：周报模板（每周复制填写）。
- `2026-W32_EXAMPLE.md`：填写示例（演示格式）。

流程：周期结束复制模板为当周文件 → 按示例格式填写 → 与 `WORK_PROGRESS.md`、`CURRENT_STATUS.md` 呼应。

## 每周日总结

- **固定每周日**（或项目约定日）汇总当周工作，产出周报 `2026-W##.md`。
- 周报素材来自：`LOGS.md`（总日志）、`WORK_PROGRESS.md`（进度）、`OPEN_ISSUES.md`（未决问题）、各证据包。
- 多智能体协作时，由**专职记录智能体**整理，或当周执行者汇总。
- 建议设置每周日定时提醒（如 cron）触发写周报。
