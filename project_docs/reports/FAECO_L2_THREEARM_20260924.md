## 3. 对照观察：random 臂（候选排序机制的价值证据）

| 电路 | fixed ΔWNS | random ΔWNS (seed 1/2/3) | random k₁st (1/2/3) |
|---|---|---|---|
| s27 | 0.10 | 0.10 / 0.10 / 0.10 | **1** / 30 / 30 |
| s382 | 0.22 | 0.19 / 0.22 / 0.19 | 17 / 3 / 1 |
| s420 | 0.97 | 0.70 / 0.95 / 0.80 | 1 / 2 / 1 |
| s641 | 0.64 | 0.70 / 0.63 / 0.45 | **123** / 1 / 39 |
| s713 | 0.13 | 0.13 / 0.13 / 0.13 | **216** / 5 / 23 |
| s820 | 0.02 | 0.02 / 0.02 / 0.02 | 21 / 1 / 2 |
| s832 | 0.09 | 0.06 / 0.06 / 0.06 | 18 / 1 / 1 |
| s953 | 0.11 | 0.20 / 0.20 / 0.20 | **185** / 1 / 28 |

随机排序普遍使 k₁st 恶化 1–2 个数量级（s641: 1→123；s713: 5→216；s953: 1→185），
最终 ΔWNS 多数持平或更差（s420 −0.27、s832 −0.03、s641 seed3 −0.19），
个别反超（s953 +0.09，代价是 k₁st 1→185）。
→ **「权重驱动的候选排序」本身有清晰价值；价值来自排序，不来自 EMA。**

## 4. §6.4 判读（事先写定的标准）

| 结果行 | 本实验命中？ |
|---|---|
| ① B(k) 不劣且 N_STA-to-first 显著更低 → EMA 反馈成立 | ❌ k₁st 0/8 更低 |
| ② 最终 ΔWNS 更高但 STA 更多 → 价值=更高上限 | ❌ 终点 0/8 更高 |
| ③ B(k) 曲线基本重合 → **EMA 无独立贡献** | ✅ **命中** |

**判读：行 ③ —— 在本实验 regime 下，L2 EMA 反馈无独立贡献。**
逐电路配对差全部为 0（最终 ΔWNS 与 k₁st），方向一致性 8/8，无单电路主导问题；
不做显著性断言（诚实标注：n=8）。

## 5. 机制层解释（为什么是零贡献）

1. **接受-失败平台期 regime**：k=8 + early-stop 下，首轮几乎必接受
   （s27/s420/s641/s820/s832/s953 的 k₁st≤2），之后 19 轮全部失败——
   EMA 只在失败轮推进（G2 契约：接受轮不动 EMA），因此 18–19 轮权重持续漂移
   （boundary/size 1.0→1.49，coverage 1.0→2.0，F5 cone 收缩从未触发）。
2. **权重漂移改变的是顺序，不是可达集**：
   - 小电路（s27/s382/s420/s820）：cone 小、可行割少，权重漂移**不足以重排**候选
     → adaptive 与 fixed 的 STA 序列**逐位相同**（已 diff eval_trials 验证）；
   - 大电路（s641/s713/s832/s953）：重排发生，但在**同一平台期**内换了探索顺序，
     没有找到 fixed 顺序找不到的改进 → 多花的 STA 全部沉没。
3. 换言之：**反馈的输入（失败类型）与反馈的输出（权重增量）之间的通路是通的，
   但通路终点（割排序）在该 regime 里对结果无杠杆。**

## 6. 威胁与边界（诚实标注）

- **k 未被设计冻结**：r2 §6.1 统一口径未含 `candidates-per-iteration`，k=8 是本次选择。
  k=1（论文 20260826 批次口径，runner 帮助文本亦注明 "1 isolates feedback"）下
  权重直接决定**唯一候选的身份**而非次序，EMA 的杠杆可能完全不同——
  **建议补跑 k=1 的 fixed vs adaptive 核心对**（§6.5 执行顺序本来就以该对为先），
  再对 L2 做最终判读。三臂中 random 臂在 k=1 下退化为 fixed，故 k=1 只补两臂。
- 本实验的失败反馈全部来自 F1/F3/F4（等价失败/patch 过大/时序增益不足），
  F5/F6 通道未触发，其对应 EMA 通道未被检验。
- 一致 STA 预算 500：4 个 run（全在 random 臂）触顶 `sta_budget` 提前停止，
  fixed/adaptive 全部 `max_iterations` 停止，预算截断对核心对无影响。
- 8 电路、单 seed 组（random 3 seed 仅作稳健性参照），不做显著性断言。

## 7. 结论与下一步

**结论**：按 r2 §6.4 事先标准，**行 ③ 命中——L2 EMA 反馈在 k=8 混合候选 regime 下
无独立搜索效率贡献**；价值定位回退到「候选空间 + 权重排序」（random 臂对照支持）。
这与 OI-012 指出的「论文表 6 缺失效反馈对照」直接相关：**当前证据不支持把
Failure-Aware 反馈作为独立核心主张**，除非 k=1 补充实验给出不同结论。

**下一步（待用户裁定）**：
1. ~~补跑 k=1 fixed vs adaptive 核心对~~ → **已完成（2026-09-24，见
   `reports/FAECO_L2_K1_DISCRIMINANT_20260924.md`）**：8/8 电路逐位相同、
   top-1 候选身份 0 次改变 → **EMA 降级，L2 封板**；
2. 依结果决定论文 §4.4/§6 表述：~~撤下独立反馈主张~~ → 确认撤下，拆分为
   「候选空间+权重排序」+「失败归因（诊断）」两条独立主张，EMA 降为可选机制；
3. L3 S（窗口局部重综合）按原计划推进——本实验同时表明增益应从**候选空间扩展**（S 的新
   候选类型）而非反馈权重大。
