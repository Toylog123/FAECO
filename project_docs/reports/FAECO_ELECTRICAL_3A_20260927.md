## 1. 这一轮要回答的问题

设计计划 §3 把 3-A 定义为**三步门**，不是"加个特征"：

$$\text{先采集} \to \text{再统计相关性} \to \textbf{才决定是否入 ranking（式 (2)）}$$

要回答的问题是：

> 在**付物理分析的钱之前**（即理想 STA 上）可得的电气量 —— slew / capacitance / fanout ——
> 能否预测"某候选的理想时序增益在物理门处**未兑现**"？

按计划纪律，**本轮不改算法**：`ranking` / `accept` / 反馈路径逐字不动，只增采集与判定；
判定规则（阈值、标签清单、最小类别数、多重比较护栏）**写在采集之前**，防止数据落地后
挑一个好统计量把一个好看的数字说进式 (2)。

## 2. 采集口径与四臂设计（结论先行：单变量对照成立）

**四臂 = 两个 regime × {对照, 采集}**；同一 regime 内两臂的**唯一自由度**是 `--capture-electrical`。

| 臂 | 开关 | 作用 |
|---|---|---|
| `phys` | `--no-feedback --physical-gate` | 物理 regime 对照 |
| `elec` | 同上 **+ `--capture-electrical`** | 物理 regime 采集 |
| `base` | `--no-feedback` | 理想 regime 对照 |
| `cap` | 同上 **+ `--capture-electrical`** | 理想 regime 采集 |

统一口径：`--period 0.5 --max-iterations 20 --candidates-per-iteration 8 --joint-k 2
--enable-buffer --workers 1 --early-stop --no-feedback --sta-budget 1600`，8 个 ISCAS89 电路，
真实工具链（OSS-CAD Yosys `0.67+146` + ABC + OpenSTA 3.1.0，`sky130_fd_sc_hd__tt_025C_1v80`）。
**32/32 run 全部正常结束**。

两条**与后续设计耦合**的口径决定（技术设计 §11.1）：

1. **电气量取自理想 STA**（不带 SPEF）。这正是"前置"的语义：特征必须在付物理分析的钱**之前**可得，
   否则不可能用于 ranking。因此本阶段的假设是"**理想网表上的电气量 → 预测物理 regime 的结果**"。
2. **为什么需要两个 regime**：主标签 `F6_physical_load_failure` 只在物理门打开时发射，
   而论文既有的物理门参数下它近乎恒真（见 §5）。若只用它，任何"无信号"都只是**标签的伪结论**。
   故同时采集理想 regime，以提供有方差的标签。

## 3. Gate 0 —— 先证明"采集关就是原样"

**在解释任何相关性之前必须证明采集臂没有被动过。** 同 regime 内两臂唯一自由度是采集开关，
故 `success / iterations / stop_reason / wns_history / 接受补丁链 / trial 序列(kind,instance,wns)`
必须**逐位一致**：

> **结果：16/16 全等**（8 电路 × 2 对），`gate.passed = True`，无缺失 run。

⇒ 采集惰性不只在 s27 冒烟上成立，而是在 **32 run / 8298 trial 行**的规模上成立。

## 4. 预算不绑定与覆盖率

**预算不绑定**：电气采集没有偷走 STA 预算。

| | 最大值 | 预算 |
|---|---|---|
| `sta_used`（全 4 臂 × 8 电路 32 个数） | **996**（phys / s832） | 1600 |

同一 regime 两臂的 `sta_used` **完全同值**；最紧的 phys/s832 也只用掉 62%。物理 regime 每候选
约 2–3 个 `sta` 记账、理想 regime 1 个，与设计预期一致。电气基线（每 evaluator 一次）不记账，
与既有物理基线采集口径一致。

**覆盖率**：单电路区间 **91.5%–100%**，全体约 96%（phys 84xx/…，见 `elec_3a_full.json`）。
未携带电气记录的 trial 是**在进入 STA 之前就因 F1 前哨被拒**的候选（本就无 STA 输出），
不是采集失败 —— 这一点由"对照臂同样不含该 key"佐证。

## 5. 标签可用性 —— F6 在规模上仍近退化（OI-015 的规模化证据）

| 标签 | 行数 | 正例 | 负例 | 正例率 | 过类别下限（≥20） |
|---|---|---|---|---|---|
| `f6`（发射 `F6_physical_load_failure`） | 4349 | 4298 | **51** | **98.83%** | 是 |
| `no_physical_gain`（`physical_delta ≤ 0`） | 4349 | 4296 | 53 | 98.78% | 是 |
| `hard_fail`（任一 `hard_gate` 事件） | 8298 | 1371 | 6927 | 16.52% | 是 |
| `no_ideal_gain`（锚定 WNS 增量 ≤ 0） | 8298 | 8191 | 107 | 98.71% | 是 |

四个标签在 8 电路全量下**都越过了 `MIN_PER_CLASS = 20` 的类别下限** —— 因此本轮判定**不是**
"标签退化导致不可判"，而是**真的有标签可用、但仍然没有信号**（§7）。但两点必须如实写明：

- **`f6` 的少数类只有 51/4349（1.17%）**，且高度集中：`s420` 20/136（14.7%）、`s641` 13/886（1.5%），
  其余六电路各 1–8 个。也就是说，除 s420 外物理门几乎**从不接受**。在一个 51 个少数样本上
  得到的 AUC 是**高方差估计**，近阈读数不应采信（§7 的判定正是据此拒绝）。
- **物理增益本身几乎恒为 0**：`physical_delta ≠ 0` 的候选仅 **448/4349 = 10.3%**，
  即约 **90% 的候选其成对物理 WNS 与打补丁前完全一致**。这正是 OI-015 关心的问题的规模化证据：
  在论文既有物理门参数（预布局 RC 估计 `unit_len_um = 40 µm`、`min_physical_gain_ns = 0.01`）下，
  该门对绝大多数候选**不改变任何可观测的物理量**，因而既不能当好标签，也不能当有效筛选器。

## 6. 逐标签相关性（预锁定判据的输出）

定向 AUC（秩、并列感知）= `max(AUC, 1−AUC)`；`signs` 为逐电路方向（+1/−1）。

| 标签 | 最强特征 | 定向 AUC | 少数类 n | 跨电路同向 |
|---|---|---|---|---|
| `f6` | `worst_max_capacitance_slack` | **0.6519** | 51 | **否**（`[1,1,-1,1,-1,1,1,1]`） |
| `no_physical_gain` | `worst_max_capacitance_slack` | 0.6458 | 53 | 否 |
| `hard_fail` | `cp_max_fanout` | 0.6093 | 1371 | 否 |
| `no_ideal_gain` | `drive_delta` | 0.6332 | 107 | 否 |

三点观察：

1. **只有一个 (特征, 标签) 组合越阈**：`worst_max_capacitance_slack` 在 `f6` 上取 **0.6519**，
   仅比阈值 0.65 高 **0.0019**；且**跨 8 个电路中有 2 个方向相反**，还落在**最不平衡的标签**上。
   这正是判据设计要拦住的情形（单标签 + 近阈 + 方向不稳）。
2. **排名靠前的多是"结构量"而非"电气量"**：`drive_from` / `drive_to` / `drive_delta`（驱动强度及其增量）
   在各标签上普遍排前，而真正的电气特征（`cp_total_capacitance`、`d_cap_slack`、`cp_max_slew`）
   定向 AUC 均 < 0.61。见 §8 的同源性分析。
3. **连续量参考**（各特征 vs 成对物理增益的 Spearman）最强也只有 **|ρ| = 0.197**（`drive_from`），
   且该量**只作参考、不参与判定**。

## 7. 预锁定判定：**NO SIGNAL**

判据（采集前写定于脚本头部与契约 §8.15）：

> **同一特征**必须在 **≥2 个可用标签**上同时满足定向 AUC ≥ 0.65，**且方向一致**（各电路同号）→ SIGNAL；
> 否则 NO SIGNAL；若无任何可用标签 → NO SIGNAL (untestable)。

**结果：NO SIGNAL。** 无任何特征在 ≥2 个可用标签上同时越阈且保持同向；最强单点读数为 0.6519，
未构成任何特征的多标签一致证据。判定同时给出可用/退化标签清单与所用阈值。

**这个"NO SIGNAL"是可信的，理由是它没有靠"标签退化"取胜**：四个标签都过了可用性下限，
判定是被**多重比较护栏 + 方向一致性**拦下的。换句话说，即便放宽到"单标签越阈即算"，
那条 0.6519 也落在 (i) 98.83% 正例、51 个少数样本的标签上，(ii) 跨电路方向不一致 ——
不足以支持"把电气量写进式 (2)"。

## 8. 结论与对论文 / 后续的含义

**决策（按技术设计 §11.3 的冻结关系，NO SIGNAL 分支）：**

1. **电气量不入式 (2)**，保持"仅采集"定位；`ranking` / `accept` / 反馈路径维持现状。
2. **3-B（把 $F_6$ 拆成 $F_{6L}$ / $F_{6W}$）不做** —— 其前提（3-A 判 SIGNAL 或出现稳定同向迹象）
   未成立；按 §11.3 如实写入 limitation，而不是硬做一个无标签支撑的拆分。
3. 论文 §7 limitation 建议一句话（待与 OI-013/OI-014 一并改）：
   > 在预布局物理模型下未能为电气量建立可泛化的判别证据，故式 (2) 不含电气项；
   > 电气量仅作采集与审计之用。

**★ 附带的方法学发现（新增，已写入 skill `metric-validity-audit`）：**

`hard_fail` 是本轮唯一"有结构方差"的标签（16.5% 正例），但它由
`acceptance_budget_violation`（1368 次）与 `F3_patch_too_large`（11 次）主导 ——
**这两个失败判定本身就是"补丁规模"的阈值化**；而它在各标签上排第一的特征恰是
`drive_delta` / `drive_to`（**补丁规模增量**）。因此该 AUC 高分是**定义式恒真**
（"改动越大越容易撞预算/尺寸门"），**不是对时序风险的预测**。

> 结论：**"退化标签"之外，还有"标签–特征同源（circular）"这一失效模式。** 若某标签的判定
> 是某特征的阈值化，则用该特征预测它是循环论证。自检问句：**"这个标签能否由该特征单独重算出来？"**
> 能 → 必须剔除同源特征，再问剩余特征是否仍有信号。

**对 OI-015 的补充证据**：本轮的 8298 行数据表明，物理门的"接受/拒绝"在 **89.7% 的候选上
不改变成对物理 WNS**（§5），且 F6 少数类仅 1.17%。这从"规模化"角度支持"该物理门在 ISCAS89 上
几乎无判别力"的判断，把此前 32/34 的小规模探针结论坐实。OI-015 的三个候选裁定
（保留参数如实报判别力不足 / 标定 `unit_len_um` / 弱化 F6 表述）仍待用户定夺。

## 9. 局限

- **电气量取自理想 STA**，本报告检验的是"理想电气量 → 预测物理结果"，**不是**物理网表自身的电气量。
  若将来改从物理 STA 取电气量，那是另一个假设，需另跑一轮。
- **物理门参数未标定**（`unit_len_um = 40 µm`）。因此 `f6` 的极端不平衡既有可能是"该特征本就无用"，
  也有可能是"物理模型标定不当"。正因如此，本轮**同时**判定理想 regime 的标签，避免单标签伪结论。
- **单次运行、无多种子**：本轮是相关性口径的**存在性检验**（有没有信号），不是效应量估计。
  给出的是"在此 regime、此参数下无可泛化判别证据"。
- 相关性判据是**预锁定**的；本轮**没有**、也**不应**在看完数据后追加新的标签或统计量。
