## 本轮教训（详见 `versions/v11/README.md` 教训节）

1. **★ 写 `.tex` 前必须归一化行尾再落盘**：本轮因 `raw.decode()` + `replace('\n','\r\n')` 造成 668 处 **`\r\r\n`**，LuaLaTeX 视为额外换行 ⇒ **83 Errors / 2 Overfull / 11 页**；且 `count('\r\n')` 与 `count('\n')-count('\r\n')` **无法**发现（仍为 668 / 0）。须断言 `b.count(b'\r\r\n') == 0`。
2. **用户文案与既有口径冲突时以取证为准，并显式列出偏离**：不得静默采纳会回退审稿修复的措辞。
3. **背景越宏大，边界声明越不可删**。
4. **字数规则随投稿目标失效，须复核而非沿用**（JCAD ≤300 字/≤150 词 → Integration 待按作者指南复核，记 OI-028）。
