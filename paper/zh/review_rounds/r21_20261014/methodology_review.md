## 总体判断

稿件的跨测试集 WNS 改善、EMA 无额外收益、结构重综合 S 的负结果和物理后验的 5/1/2 分布均有可定位的证据。其主要价值是公开工具链上的多类型候选探索与失败诊断，实验也主动保留了不利结果。当前最危险的缺口是“哪个实验验证哪个机制”：核心效果表的族 C 运行器没有使用式 (2) 的加权割，提交方式也不同于算法 1；因此，族 C 的 1.07 ns 与首次改善指标能够验证该运行器中的候选类型与评估顺序，不能单独承担文中完整加权割框架的机制归因。第二个缺口是历史实验族的 revision 漂移已有实证，但当前正文没有说明。第三个缺口是“有限验证预算”与固定轮数下的终点收益容易被读成等额实际 STA 成本的比较。以上均可先用既有证据明确表图的实验对象与解释范围，不必本轮重跑实验。是否新增权重消融，属于之后加强机制证据的选择。

## 优点

1. **失效机制没有被包装成独立增益。** `sec:ablation` 对 EMA 的终点、首次改善和最大 B(k) 相同作了明确说明。实查 `experiments/20260924_threearm_aggregation/threearm_report.json` 与 `experiments/20260924_l2_k1_aggregation/k1_discriminant.json`，八电路 Fixed/Adaptive 的终点差全为零，k=1 判别的候选身份改变为零。这比仅比较启用反馈的主实验更有归因价值。
2. **S 的负结果控制较完整。** `sec:s_boundary` 保留 76/126 个映射后变浅、0/126 WNS 改善和 90/126 WNS 下降。实查 `experiments/20260928_s_l1_ablation/aggregation/summarize_s_l1.json`，unique=candidate=measured=126，on/off 八对终点全部持平。当前结论限定到本窗口构造与映射流程，较为合适。
3. **功能与时序的成功分母已区分。** `tab:overview` 与 `sec:ood` 单独报告 b17 的一个未证明点和 picorv32_regs 的无 setup 路径，避免把“同函数尺寸替换”当成完全 SEC 的替代结果。b06 的 WNS 持平也没有被计入严格改善比例。
4. **物理不利结果有明确数字。** `tab:pr8` 保留 s420、s953 的负收益和 s832 的持平。实查 `post_route_audit_summary.json` 与 `pre_layout_audit_summary.json`，逐电路数值与当前表一致。

## 已证实问题

### M1（Major）：族 C 的效果/排序证据与正文加权割机制之间仍存在归因缺口

**定位：** 摘要核心思想句、§1.3 贡献 1、`sec:mechanism`、`sec:ablation` 第一组、`tab:ablation`、`tab:efficiency`、结论第一段。

**实查事实：**

- `code/scripts/run_hybrid_repair.py` 使用 OpenSTA 报告中的 critical instances 逐实例枚举 R/G/B，再尝试联合修改；不导入 `rseco.cut`，不计算 `cost(v)`，没有 λ 参数。
- 同脚本的 `--random-order` 对每个实例内部的候选列表执行 shuffle，关键实例的遍历顺序仍来自 STA。默认按实例评估全部候选后选择最佳候选；随机顺序可以通过平局选择、预算截断与后续网表演化影响结果。它不是对加权割/覆盖割融合列表的全局随机化。
- 该运行器在同一轮内逐实例更新 text/current_wns。`experiments/20260807_multiround_8c_067/s641_run.log` 的 round 1 中有多次提交，WNS 由 -1.63 经 -1.25、-1.07 等逐步改善。算法 1 则明确“同轮候选共享 N、该轮一旦提交其余作废”。这两个实验对象不能默认为同一个搜索流程。
- 族 C 数字本身可复核：`experiments/20260807_multiround_8c_067/convergence_summary.json` 的混合平均为 1.074 ns，`experiments/20260826_aggregation/ablation_summary.json` 支持纯 G/纯 B/三随机种子的当前数字。

**危险替代解释：** 族 C 优势来自多类型动作、关键实例遍历及平局/提交策略，而非式 (2) 的多特征节点代价或 C_w/C_c 互补边界。当前数据不能排除该解释；这不是“加权割无效”的证据。

**本轮可做：** 在 §4.4 第一组与表图注中直接交代它是关键实例枚举运行器的候选类型/顺序对照，说明不单独隔离式 (2) 的权重项或两种割来源。将“排序减少开销”对应到具体对照，不让 1.07 ns 暗示加权割被消融验证。算法图应展示受审主流程；族 C 的结果图应标明其运行器与提交粒度。若后续要将加权割本身作为实证主贡献，才需要冻结 revision 下的候选源/权重消融，遵守已暂缓安排。

**证据：** 上述代码与原始 log；`project_docs/OPEN_ISSUES.md` 的 OI-026 取证更正也独立记载族 C 不使用 cost(v)。本意见以实际脚本为依据，不依赖旧审稿结论。

### M3（Major）：固定轮数终点与有限验证预算效率的证据需要分开解释

**定位：** 摘要“提高有限验证预算下的搜索效率”、§1.3“减少候选级评估开销”、`sec:ablation`、`tab:ablation` 表注、`tab:runtime`。

## 需核实的问题（不据此指称结果错误）

### U1：族 C 各臂的 TNS-aware 设置是否真的一致？

**定位：** `sec:setup`“其余实验以严格 WNS 改善为主要接受条件”、`tab:ablation`“相同……预算”。

混合列的 `convergence_summary.json` 明确记录 `hybrid_config = rounds=20, R+G+B+JOINT, tns-aware`。纯 G/B/随机的 `hybrid_result.json` 保留 trials 但没有 tns_aware 与运行 argv；因此目前不能独立确认各臂都是相同 flag，也不能断言它们不同。TNS 平台接受能改变后续网表和终点，是有实际影响的混杂因素。建议补充材料列四臂完整命令、STA 上限和 TNS flag；若命令无法恢复，明示不完整，而不是补写推测参数。证据路径：上述 C summary、`experiments/20260826_ablation_pureG/s641/hybrid_result.json`、`code/scripts/run_hybrid_repair.py` 的 `_accepts()`。

### U2：b06 的“输入电容限制”归因有没有候选级负载证据？

**定位：** `sec:itc99` b06 段。

原始 `experiments/20260826_itc99_main/b06/b06/eval_trials.json` 支持 G 尺寸替换后不改善，例如首个 or4b_1→or4b_2 候选 WNS=-0.71 ns，而基线为 -0.56 ns；但该试验中的 max_capacitance 等字段为 null。这不等于库输入电容不存在，也不证明电容是唯一主因。建议用既有 Liberty pin capacitance 和成对路径报告，说明上游/下游延迟如何变化；无法定位时，将其写成待检验的电气解释，保留“664 次未严格改善”的已证实结果。不能仅以换大门更差反推全部因果链。

### U3：纳入规则需提供可审计的排除清单

**定位：** `sec:setup` 基准电路纳入规则。

目前“成功映射并有有效 setup 路径”是可操作的筛选规则，但正文没有说明其他 ISCAS89 与 ITC-99 b16 等为何未纳入、是否在观察修复收益之前决定。当前证据不能证明有择优纳入。建议利用既有 mapping/STA 日志制作补充表：候选总体、纳入/排除原因、是否在修复前判定；用户暂缓大规模验证，本轮无需新接入基准。证据入口：当前 setup 规则、`PAPER_EVIDENCE_MANIFEST.md` 的 A/B 族输入目录。

### U4：简化 SPEF 门控的通过/拒绝是否能代表真实物理误判率？

**定位：** `sec:phys_closure` 的 F6 结论。

已独立 raw_decode 实查：`experiments/20260805_phys_closure/s382_big/s382/eval_trials.json` 首对象共有 325 trials，其中 physical_failure=50；`b18_light/b18/eval_trials.json` 首对象为 486 trials，其中 physical_failure=6。正文“50/6 个复测失败”有证据，不能误写成全部 325/486 都做了物理复测。另一方面，40 μm/unit 模型未标定，且 `experiments/20260805_parasitic_s382_scan/u40/summary.json` 显示 ideal_delta=0.01、spef_delta=0.00。它能证明模型下收益消失；不能仅据 F6 次数推断真实物理误判率或反馈改善。建议图注注明简化模型与阈值，若制作筛选漏斗，应分别列全部 trials、跨过 10 ps 门槛、完成复测、F6 和最终接受。证据纪律同时见 manifest 族 A″、OI-015/OI-016。

## 统计与结论使用建议

- 该研究属于固定工程基准上的确定性算法比较。逐电路配对差、实际成本、种子范围与失效比例，比一律补 p 值更有解释力。候选之间共享网表、窗口和路径，126 个 S 候选不应被当成 126 个独立电路来计算普遍成功率的置信区间。
- 三随机种子主要描述该基准上的顺序敏感性；不能将“三种子均值”解释为高精度的随机算法总体估计。保留每种子点即可增强透明度。
- “其余无退化”在 WNS 单调接受下也包含算法约束的结果，并不单独证明一般鲁棒性。其价值应与 SEC 状态、hold/TNS 与物理后验结果一起解释，当前可保留准确的 WNS 口径。
- F4=2434/4044 的 60.2% 是此配置的候选评估占比，功能检查前置会改变进入各层的样本。它支持主要观察瓶颈为收益不足，不宜直接推出功能保持本身容易或失败分类已经改善搜索效果。
