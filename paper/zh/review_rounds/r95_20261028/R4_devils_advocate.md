## 最强反论

这篇稿子用一组**不等预算、且自变量从未真正变动**的对照，证明了时序优化的默认做法有效。W0/U0 只做节点割、零改善，W1 引入覆盖后转正；但由稿件自己的合计可算出：W0+U0+C 三臂 24 次运行共用 1828 次 STA（约 76 次/运行），W1 为 106 次/运行——多花 40% 测量换来了收益，"覆盖有效"与"花得多有效"在数据上不可分。更严重的是 W1 与 U1、W0 与 U0 的候选池与访问次序"分别一致"（303）：被称作"加权容量"的自变量根本没有改变候选集合，这不是"未观察到差异"，而是操作检验失败。而 C（仅覆盖）与 W1 终点完全相同（301），说明式(2)、最小割与 Edmonds–Karp 全部惰性；剩下的贡献只是"把 STA 报告里的实例放进候选区"，与默认实践无异，而稿件从未与这一平凡基线作过比较。

#### C1 — 覆盖效应与"多花测量"完全混淆；且全文动机所依赖的预算从未触顶

**位置**：§4.1 301；§4.2 313；§3.4 258（500 次新 STA 预约上限）；293（8458 记录 / 6858 次新 STA / 192 次提交 / 72 次基线 STA）；摘要 94、关键词 97、§5.2 463。

**攻击**

1. 用稿件自己的总数即可反解出被隐去的一臂：6858 − 847（W1）− (1046+919+944)（UR1–3）− 1274（L）= 1828，对应 W0+U0+C 共 24 次运行，均值 76.2 次/运行；W1 为 105.9 次/运行，高出 39%。L 为 159.3 次/运行。**"覆盖"与"更高的 STA 支出"在 8 个电路上完全共线**，稿件没有任何等预算对照来分离二者。
2. 稿件在 313 主动提到"仅节点割消耗较少 STA 但没有改善"，却把它当成本文结论的旁证而非混杂因子（confounder）。这一处理方向是反的：在预算可取的前提下，终点随支出单调上升是搜索类方法的普遍性质，"覆盖"并未被单独识别。
3. 关键事实：**500 次上限在所有臂均未被触及**（最高 L 为 159 次/运行，约为上限的 32%）。因此在受控实验中，"测量预算"不是约束；847 vs 1046 的 19% 差异没有任何决策后果——两条臂都在未触顶的情况下自然停止于同一终点。摘要（94、113）、关键词"时序评估预算"（97）、§1 129 "当测量预算有限时"所建立的整个问题动机，在实验里不成立。
4. §4.2 315 已经报告：s27 的 UR3 只需 36 次（W1 需 41 次），s420 随机臂在部分共同预算点领先至 0.17 ns。也就是说，**在任何被检验的紧预算点上，覆盖优先都不支配随机顺序**。那么"总测量成本更低"这一唯一效率主张，其适用域是一个预算不紧、也无人被支配的区间。

**作者的最低退让线**

- 删除"时序评估预算"作为关键词与问题动机，或
- 【需外部资源】补一组等预算对照：每臂硬性限定同一新 STA 次数（例如 60 / 100 / 200 三档），报告各档终点；并说明 W0/U0 是"候选耗尽"还是"预算耗尽"停止。仅凭此一项即可判定"覆盖"是否被识别。
- 若不补：必须把全部效率主张退回为——"在本实现与本次运行中，覆盖臂花费更多 STA 且终点更高；覆盖的独立贡献未被隔离，B(k) 曲线未显示任何预算点上的支配。"

#### C2 — 操作检验失败：所谓"加权容量"对照没有改变任何被观察对象

**位置**：§4.1 301–303；式(2) 180–188；191（五个权重均为 1，系数 0.01/0.1 固定）；表 2 285–286；摘要 94/113；结论 463。

**攻击**

稿件写："W0 与 U0、W1 与 U1 的**终点、候选池和访问次序分别一致**"（303）。候选池逐一相同意味着加权割集 $C_w$ 在加权与统一容量下相同，或差异被 8 项区域上限（197）整体截断。无论哪种，该对照都没有对研究对象施加任何扰动。

以**零操纵**的对照报告**零效应**，不是"未观察到差异"这一实证结论，而是实验设计失效（failed manipulation）。摘要 94 与 113 仍把"加权与统一容量未观察到差异"写成一项发现，等于把一次未遂的操纵当成一条知识。

进一步地：若 $C_w$ 在五个 $\lambda$ 全为 1、两种容量设定下都产生同一个割，则式(2) 的五个权重项与两个固定系数组成的这套代价函数，在 8 个电路上**没有可观察输出**。这不是"调参不够好"，而是该构造在当前形式下不可检验。

**作者的最低退让线**

- 补 manipulation check（**无需外部资源，用现有 72 次运行记录即可**）：逐电路报告 W 臂与 U 臂的 $C_w$ 门集合是否逐门相同、区域数是否被 8 项上限截断、截断前后的割集是否不同。
- 若确认相同：删除摘要 94/113 与结论 463 中"加权与统一容量未观察到差异"的表述，改为"在本组输入与全 1 权重下，节点容量未改变割集，该因子未被检验"。二者在学术上不等价，前者是结论，后者是空缺。

#### C3 — C ≡ W1 使 §3.2 整体惰性；方法的真实内容是一个从未被比较的平凡基线

**位置**：301（"仅覆盖的 C 到达相同终点，在 s641 少用 8 次 STA，其余实例与 W1 相同"）；303（"C 能够达到相同终点还说明，组合两个区域来源未在本组增加终点收益"）；§3.2 全节（168–193）；193（$O(VE^2)$）；§1 135 的三项贡献。

**攻击**

1. 仅覆盖臂在全部 8 个电路上达到与完整方法相同的终点，且在一个电路上更省。因此加权割区域对**终点收益与测量成本均无正贡献**。按稿件自己的判据，式(2)、节点分裂图、最小割、复杂度分析应从方法中删除，而不是保留为"另一来源"（303 已承认"为后续简化区域生成提供了直接依据"，但正文与摘要未据此简化）。
2. 删除之后，方法的全部内容是：$C_c = P \cap C_i$，先按 $P$ 顺序取实例，再枚举 R/G/B/JOINT。而 $P$ 的定义就是"STA 最大延迟报告中的实例"（166）。**这正是工业界做预布局 ECO 的默认起点**——看报告、在报告实例上改。稿件全文没有任何针对"top-k 报告实例、按报告顺序枚举 R/G/B"这一平凡基线的比较。问题在于，**C 就是这个基线**，而 C 不劣于完整方法。
3. 由此产生一个稿件未处理的推论：如果 C 是最省的臂（s641 已证实少 8 次），那么真正的效率结论应是"C 比随机顺序省得更多"，而非"W1 比随机顺序省 7.8%–19.0%"。稿件却把 W1 而非 C 拿去与 UR 比较，**选错了被评价对象**。

**作者的最低退让线**

- 在表 2 与正文中把 C 明确标注为 **trivial baseline**，并写出"完整方法（W1）未超过该基线"；把贡献重心从"区域构造"移到"提交/缓存/预算的逐事件可复核记账"。
- 若坚持保留 §3.2：必须给出**至少一个电路中 $C_w$ 严格优于 $C$** 的实例（终点或 STA 成本任一项）。找不到，则该节按稿件自身逻辑应删。
- 无论哪条，摘要与结论不得再把 0.161 ns 归因于"区域构造"。

#### C4 — 受控区间被三重人为封顶，臂间差异被压进作者自设的判定带

**位置**：164（"不转向新报告中的另一最差端点"）；220（TNS 容差为 0）；258（20 轮 / 500 次）；301（"5 个电路超过该带…余下 3 个低于本电路噪声分辨率"）；表 4 383（混合 20 轮均值 1.07 ns）。

**攻击**

1. 受控矩阵固定单一目标端点 $t$（164 明示"不转向新报告中的另一最差端点"）。$t$ 修好之后，全设计 WNS 立即由次差端点决定，可获收益被 $(WNS_{\text{次差}} - WNS_t)$ 硬性封顶。再叠加 TNS 零容差（220）这一极严接受门与从未触顶的 500 次预算，**受控区间只覆盖了总头寸的一小部分**。
2. 同一 8 个电路、同一 0.5 ns 周期，作者自己的 20 轮混合配置取得 **1.07 ns**（表 4），是受控臂 0.161 ns 的 **6.6 倍**。这不是"受控更保守"，而是说受控实验在一个人为压低的区间里比较各臂——臂间差异自然被压缩到与自设 2σ 带（0.0246–0.0847 ns）同量级。
3. 因此"3 个电路低于噪声分辨率"（301）**不是方法在某些电路上失效的证据，而是封顶的算术后果**。把它写成"余下 3 个低于本电路噪声分辨率"，实际上是用一个统计措辞掩盖了一个实验设计约束。
4. 更尖锐的一问：如果固定端点只能拿到 0.161 ns，而换用逐实例提交的旧运行器能拿 1.07 ns，那么**限制收益的是受控协议，不是被研究的方法**。稿件由此无法回答"覆盖优先在真实（多端点）ECO 场景下值多少"。

**作者的最低退让线**

- 明确写出该区间的 headroom 上限，并证明各臂比较发生在封顶之前（例如报告每臂平均提交次数与终点后次差端点的 WNS）。
- 或【需外部资源】解除固定端点限制重跑 72 次矩阵。
- 不补：删去"5/8 超带、3/8 低于噪声分辨率、89.1%、0.12120 ns"作为**效应证据**的用法（可保留为描述性统计），只保留"W1 与 W0/U0 的终点差"这一更弱但仍成立的陈述，并在摘要中说明该差在一个被单端点封顶的区间内测得。

#### C5 — 电气合法性与物理有效性：修复网表在签核意义上可能不合法，且增益在第一个物理检查点归零

**位置**：400（"功耗、hold、最大电容及转换时间未作为本组验收项"）；表 5 405–418；421（OpenROAD：5 改善 / 1 持平 / 2 退化）；435（RC 为估算、不由几何提取）；表 6 437–448（ℓ=10 → +0.11；ℓ=40、160 → 0.00）；§1 135（把物理后验列为贡献之一）。

**攻击**

1. 被接受动作的主体是 G（同族增大驱动）与 B（插缓冲）——这两类恰恰是最容易违反 **max_transition / max_capacitance** 的动作。稿件明确声明不检查这两项（400），因此"修复后网表"在签核流程中**可能直接是非法 ECO 结果**。一篇以"修复时序违例"为目标的论文，交付一个不保证电气合法的网表，属于目标函数与验收口径的错配。
2. 唯一的双侧、逐引脚核对后验（s382）显示：理想线网 0.15 ns，ℓ=10 保留 0.11 ns，ℓ=40 与 160 归零（437、表 6）。三个 ℓ 取值没有任何标定，稿件自认"不由几何坐标提取"（435）。因此这三点**既不支持"收益保持"，也不支持"收益消失"**——它们只支持"未知"。
3. OpenROAD 后验 2/8 符号翻转（421），且脚本未设 I/O 延迟、输出负载、输入转换、时钟不确定度（423）。在这个条件下，2/8 退化既可能是真实物理效应，也可能是脚本缺省值的产物；稿件无法区分。
4. 把这一组净结果为"未知"的后验写进 §1 135 作为三项贡献之一（"面积与物理后验检验适用范围"），是把 limitation 包装成 contribution。

**M1 — 统计：n=3 且仅对对照组重复，宣称的最小节省小于种子离散度**

位置：313、295、S3 表 `tab:runtime` 449–451。

**M2 — 判定带与"STA 确定性"自相矛盾：2σ 不是噪声**

位置：301（"按各电路自身的候选级判定带（2σ，0.024558–0.08474 ns）衡量…低于本电路噪声分辨率"）；437（"同网表控制差值为 0，全部 8 次注释回放均无未注释或部分未注释驱动"）；433（43 组失败控制被弃用）。
攻击：若同网表重测差值为 0、8/8 注释回放与 STA 结果一致，则 STA 在给定网表上是**确定性**的，不存在测量噪声。那么 2σ 描述的只能是**候选之间的效应离散度**，而不是噪声下限。用候选效应分布宽度去判定"某电路的效应低于噪声分辨率"，是范畴错误：它既可能真实存在（只是小于典型候选幅度），也可能完全不存在，该统计量无法区分。
退让：改为"低于候选效应中位幅度"这类可辩护表述；或【需外部资源，成本极低】对同一网表重复 STA 20 次给出真实重测 σ。不补则删除"噪声分辨率"一词及基于它的 3/8 判定，同时"89.1%"与"0.12120 ns"的推导链失去前提。

**M3 — b17 逐电路放宽验证时限，属 n=1 的按例调参**

### 过度概括检测

**可外推到**：单一工艺库（SKY130 HD）、单角（TT 25 ℃/1.8 V）、理想线网、单端点、≤228 单元、0.5 ns 人为制造违例、8 个 ISCAS89 随机逻辑电路上的"候选访问顺序与总 STA 次数"之间的关系。此范围内，稿件的主张基本可信（除 C1–C3 的混杂）。

**不可外推到**：

1. **规模**。核心证据的电路为 11–228 个单元。s27 有 11 个单元——这不是"design"，是一个门级练习。工业预布局 ECO 的对象是 $10^5$–$10^7$ 门。稿件用 b18/b19 尝试覆盖规模，但两者是**不可复现的单次运行**（S3 313），且 b18 的结果是 $-13.34 \to -13.27$（改善 0.07 ns，占违例的 0.5%）——在一个 7.57 万单元设计上、0.5 ns 周期下出现 $-13$ ns 违例，说明该流程在此规模下本身不成立，不构成 ECO 场景。
2. **多端点**。固定端点 $t$（164）是全文最硬的人为限制；真实 ECO 必须在违例集合上迭代。0.161 ns 不可与任何文献数字并列，因为其上限由 $(WNS_{\text{次差}} - WNS_t)$ 决定。
3. **多角 / OCV / 时钟树 / useful skew / hold**。全部未涉及，且 hold 与 max_cap 被明确排除（400）。
4. **"结构代理无用"这一结论**。仅基于一个 5 项式在 λ=1、8 个电路、2 种容量设定、且操纵失败（C2）的条件下成立。推广到"结构特征/代价项不值得研究"是越界，455 的"而非仅增加代价项或候选规模"即属此类越界。
5. **"跨测试集验证"**。ITC-99 为每电路单次运行、无种子、无对照臂、部分有按例调参（b17）、3 例功能不可证、身份不完整（C6）。这是 observation，不是 validation。
6. **"预布局候选筛选"这一标题承诺**。稿件实际研究的是"在给定报告后如何排序候选"，而非"如何筛选"——筛选（screening）意味着有假阳性/假阴性率，本稿未定义、未测量。标题与内容的范围不匹配。

### So what?（谁的行为会改变）

**若全部结论成立，行为改变清单如下：**

1. 作者的代码库：删除式(2)、节点割、Edmonds–Karp、EMA（约省下 §3.2 全部实现）。这是确定的、可执行的改变。
2. 读者的实现选择：不要为一个不起作用的代价函数调参；不要指望 EMA 反馈。**这是本稿唯一可能被别人采用的结论**，而它的证据是一次操纵失败的对照（C2）。
3. 签核/实现工程师：**不会改变任何行为**。理由有三：(a) 增益在理想线网测得，ℓ≥40 μm 归零（437）；(b) 未检查 max_transition / max_capacitance（400），结果可能不合法；(c) 固定单端点（164），不覆盖真实违例集合。0.161 ns 在真实流程中不足以触发一次 ECO 决策。
4. EDA 研究方法社区：可能被引用的只有"负结果"部分——加权割无用、结构候选无用、EMA 无用。但三条负结果各自建立在一次未遂操纵、一个未标定的实现、一对完全相同的终点之上（C2、390、388），可引用性有限。

**结论**：本稿的净信息量约等于"我们在自己的实现上，把三件不奏效的东西各测了一遍，并用一套非常讲究的记账方式记录下来"。这在工程上有价值（记账方法确实可复核，见"非缺陷观察"），但作为期刊论文的**方法贡献**，其行为改变半径接近于零。

W0+U0+C 三臂 76.2 次/运行（零或与 W1 同终点），W1 105.9，UR 121.2，L 159.3。这个序列同时解释：(a) W0/U0 零改善；(b) W1 正改善；(c) L 与 W1 差异不可归因排序（313 已承认）。稿件用"仅节点割消耗较少 STA 但没有改善，不属于相同收益下的效率优势"（313）一句带过，但这恰恰是必须排除的混杂，而不是可以 dismiss 的脚注。

**E2（次强）— 区域规模，而非"报告实例"这一语义。**
六门例给出直接证据：$C_c$ 含 3 门、$C_w$ 含 1 门（201）。覆盖区域天然大于割区域。因此"覆盖优先有效"可能是"较大区域有效"的代理。若成立，正确结论是"区域越大越好直到上限"（与 M8 的 8 项上限直接相关），而这与"是否来自 STA 报告"无关——一个纯粹由拓扑选出的、同等大小的区域应当同样有效。**稿件从未做这个对照，也从未报告任一臂的区域门数分布。** 这是对全文因果主张最直接的替代解释，且用现有记录即可部分检验（报告每臂区域门数即可看出是否共线）。

**E3 — 提交驱动的路径依赖，而非排序本身。**
317 自认"全程固定同一候选全集的纯排序因果重放仍未取得"。有了提交，"先访问大区域"会改变提交时刻，从而改变后续全部状态。于是 W1 与 UR 的差异可能是"首次提交更早 → 报告刷新更早 → 后续候选更好"，而不是"顺序更好"。这可以由同一候选全集的离线重排（纯排序，不提交）排除——稿件明确未做，却仍保留"覆盖优先的价值体现在总测量成本"（135、463）这一因果表述。

**E4 — 选择偏差 / 赢家诅咒。**
接受判据为 $\Delta_{\mathrm{WNS}}>0$、容差 0（220），20 轮内对约 100 个候选取首个正值；终点又取多轮提交的累积最大值。若存在任何候选级抖动（无论来自 STA、映射还是模型），max 会系统性上偏。稿件无 null 控制（例如对语义等价、仅重命名的候选重测，观察其 $\Delta$ 分布）。**0.12120 ns 的净额与"3/8 电路恰在带内"这两个现象，与"约 2–3σ 的选择上偏"完全一致**，稿件无法区分。

**E5 — 未被排除的平凡基线。**
"在锥内所有实例上按拓扑序枚举 R/G/B，预算耗尽即停"。这是任何工程师的第一步；若它与 W1 同效，则"报告实例"这一信息源本身无价值。C 已接近该基线但**仍以 $P$ 为实例顺序**，因此 C 的成立不能排除 E5。这是最低成本、最高信息量的一个缺失对照。

**E6 — 同终点 ≠ 同质量。**
847 vs 1046 的比较只固定 WNS。URA 三臂终点网表的面积、单元数、物理转移性均未报告（表 5 只给了 W1）。若随机臂以更大面积换来同一 WNS，则"省 19% STA"并非效率优势，而是"用了更少测量、付了更多面积"——一个未被计入的交换。

## 非缺陷观察（Observing, not defect）

以下看起来像弱点，实为负责任的写法；本审稿的多条反论正是建立在作者主动披露之上。若这些披露被删除，稿件会更难被驳倒，但也会更不可信。

1. **不平均、不插值、不跨电路合并**：72 个终点全展示（307），图 3 图注明确"全部配置及局部交叉保留"（321），B(k) 曲线"未作跨电路平均或插值"（S3 385）。
2. **拒绝把 STA 次数换算成墙钟加速**（317）。这在同类文献中很少见，且直接限制了作者的宣传空间——值得肯定。
3. **拒绝用未分层总均值替代已证子集**（331："不能用未分层总均值代替功能已证明子集的效果"）。分层报告 16/19（0.208）与三态 3 例（1.61）是正确的做法；问题只在表 3 未贯彻（M4）。
4. **把不可评估对象移出分母而非记为成功**：`picorv32_regs` 无 setup 路径，改善与 SEC 均标"不适用"（333、表 3 注）。
5. **保留失败的控制实验并拒绝使用其数据**：原层级 SPEF 扫描出现 43 组部分未注释驱动，稿件停止而不采其时序值，并明确"仅返回码为 0 或同网表时序差值为 0 不足以通过验收"（433、S4 516）。这是本稿方法学上最强的一段。
6. **区分"零读数"与"效应消失"**（437）。在 0.01 ns 报告粒度下拒绝宣称因果，是正确的谨慎。
7. **用"结构身份核验"而非"四态证明"描述 X 常量**（248、S2 226）。没有把弱证据包装成强证据。
8. **主动报告反例**：s713 混合臂劣于随机（362）、s382 台账缺失（362）、s27 的 UR3 只需 36 次（315）、s420 随机臂领先 0.17 ns（315）、阶段 S 的 0/126（390）。这些都不利于作者的叙事，但都写了。

**给作者的一句公道话**：本稿的记账纪律（候选记录 / 新 STA / 提交 / 证明点数四者分列，缓存与前置拒绝不计费）在同类工作中属上乘。若把本文重写为"预布局 ECO 候选搜索的可复核评测协议 + 三条负结果"，其价值会高于现在这个"方法 + 效果"的框架——因为后者的效果部分恰好是证据最弱的部分。

## 决定建议

**Major Revision（条件性）**

**理由**：稿件的诚实度与记账纪律达到发表水准，但支撑标题承诺（"候选区域构造"）的核心因果主张未被识别：覆盖效应与 STA 支出共线（C1）、加权容量因子操纵失败（C2）、仅覆盖臂与完整方法等效（C3）、受控区间被单端点与零容差封顶（C4）、修复网表未做电气合法性检查且增益在物理检查点归零（C5）、而唯一宽泛的"泛化"证据不可复现（C6）。这不是"贡献不足"，而是**贡献被错误定位**：真正成立的是负结果与评测协议，被写成的是方法有效性。

**必须完成的退让（按优先级）**

1. C1、C2、C3 三条为本轮的门槛项。三者共同决定论文是"方法论文"还是"负结果论文"。作者必须选择其一并全文一致：
   - 若选"方法"：补等预算对照 + manipulation check + 至少一个 $C_w$ 优于 $C$ 的电路（前两项用现有记录即可，第三项【需外部资源】）。
   - 若选"负结果"：删除 §3.2 的主体地位、把 C 标为平凡基线、重写摘要与结论、标题去掉暗示"构造有效"的表述。
2. C4、C5、C6 为次级门槛：至少完成 C5 的 max_transition/max_capacitance 报告（成本最低、影响最大），并把"物理收益保持"从贡献降为 limitation。
3. M1、M2、M4、M7 可全部用现有数据完成，不需要 EDA 工具链；建议在修订稿中一次补齐，这会显著提高稿件在统计层面的可辩护性。

**转 Reject 的条件**：若作者坚持现框架、拒绝 C1–C3 的任何一条退让（尤其是拒绝承认 C 为平凡基线、或拒绝给出 $C_w$ 与 $C$ 的对照），则本稿的净内容为"对自身实现的负结果 + 一套记账协议"，与标题及摘要承诺不符，建议 Reject（并欢迎以负结果/评测协议形式重投）。
