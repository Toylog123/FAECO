# S3 补充材料：顺序等价检查（SEC）逐实例结果

> 随稿补充材料（T20，2026-09-30 整理）。来源：统一跨测试集评估的 SEC 批量汇总（30 实例）+ b17 phase-2 复跑的 SEC 明细记录。所有实例均以独立全网表顺序等价检查（Yosys miter + SAT / equiv 流程）验证修复网表与基线网表等价。

## 1. 汇总口径（与论文 §4.5 一致）

- **30 个测试实例** = ISCAS89 8 + ITC-99 19 + PicoRV32 3；
- **29 个实例产生实际网表修改**（`picorv32_regs` 为存储簇、无 setup 时序路径，未产生候选，输出网表与基线一致，记 N/A）；
- **28/29 个修改网表完全证明**（唯一例外为 b17：12812 个等价点已证明，仅剩 1 个未证明点，见 §3）；
- 分组计数：ISCAS89 **8/8**、ITC-99 **18/19**（例外 b17）、PicoRV32 **2/2**（第三个实例 N/A）。

## 3. b17 的唯一未证明点（与论文 §4.5 一致的单独报告）

b17 phase-2 复跑接受的补丁为同族尺寸替换（`nor4b_1 → nor4b_2`）。SEC 报告 **12812 个等价点已证明、1 个未证明**：

- 未证明信号为替换门输出连线；原因是 Yosys `find_same_wires` 在尺寸替换后两侧线名不一致时的已知局限；
- 两单元的 Liberty 逻辑函数一致，属**工具局限**而非逻辑不等价；
- 因此 b17 计为"12812 已证明 + 1 个未证明点（同函数尺寸替换）"单独报告，不计入"完全证明"的 28/29。
