# 审稿回复模板

> 针对审稿意见逐条回复。复制为 `response_to_reviewers_<轮次>.md`。

## 意见处理原则（回复前先做）

1. **先判断是否缺陷**：意见指出缺陷 / 不足时，**优先补充实验、完善设计、增强证据**，而不是降级论文描述。
2. **行动优先级**：补实验（新增证据）> 完善设计（改方法 / 实现）> 澄清措辞（口径 / 术语）> 降级声明（最后手段）。
3. **降级是最后手段**：仅在技术 / 资源 / 时间硬约束下确实无法补充时才允许缩小范围或弱化声明，且必须说明原因、影响与恢复路径。
4. **每条意见对应一个行动**：写明补了什么、改了什么、对应哪份证据。

## 通用规则

1. 每条回复必须指向证据包或具名基线，不得凭空声称。
2. 区分「实测」与「估计」。
3. 中英文两版结论一致。
