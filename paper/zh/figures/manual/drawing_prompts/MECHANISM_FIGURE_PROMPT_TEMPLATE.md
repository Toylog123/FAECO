# 机制图设计提示词：<图名>（fig<N>_<名称>）

> 给绘制者的**详细设计提示词**。要求：**结构示意，不只是简单流程**——标注模块、连线、数据流、层次与关键接口。
> 论文中当前放**草图 / 占位**（`figures/manual/figures/`），最终由绘制者按本提示词手工绘制。

## 一、图目的

（这张图想表达什么核心信息？一句话。）

## 二、结构示意（核心，必须详细）

### 2.1 层次 / 分区

（图分几个层次 / 区域。例：输入层 → 处理层 → 输出层；或 数据平面 / 控制平面。）

### 2.2 模块清单

| 模块 | 位置（上/中/下/左/右） | 职责 | 关键标注 |
|------|------------------------|------|----------|
| 模块 A | 中偏左 | … | 端口 / 参数 |
| 模块 B | 中偏右 | … | … |

### 2.3 连线与数据流

- 模块 A → 模块 B：`<数据 / 信号名>`（实线，箭头含义）
- 反馈回路：模块 C → 模块 A（**虚线**，标注"反馈"）
- 控制 / 数据分离：控制信号用虚线、数据流用实线

### 2.4 关键细节

- 需突出的内部部件（寄存器 / 队列 / 比较器 / 仲裁器等）
- 需标注的信号 / 端口 / 接口名
- 阶段 / 时序标注（如 Stage 1、Stage 2）

## 三、样式要求

- 宽度：单栏（约 8cm） / 双栏（通栏）
- 配色：黑白 / 灰度（期刊要求），避免彩色依赖
- 图内文字：8pt 左右（中文书宋、英文 Times），图内不生成标题 / 图号 / 水印
- 线型：主数据流实线、控制 / 反馈虚线

## 四、草图与交付

- 论文当前放**草图 / 占位**于 `figures/manual/figures/`。
- 绘制者完成后：源文件存 `figures/manual/figures/`（draw.io 等），定稿 PNG 导出 `figures/manual/figures/`。
- 提示词文件：`manual/drawing_prompts/<figN>_<名称>_prompt.md`。
