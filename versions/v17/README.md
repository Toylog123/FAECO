## 本轮教训（写入 `MEMORY.md`）

1. **「接受用户文案」≠「只替换一句话」**：用户给定段落常与原段落**同头**（如「综上，在本文实验范围内，」），必须先在 `.tex` 内定位**同头句**再定替换边界；否则会产出重复的引导语。凡偏离（替换范围大于方案「现状」列）须**明写、不静默采纳**。
2. **压页实验有严格的回退纪律**：每次只改一处、立即编译复核页数、不成功即回退到已知基线（本轮两处实验均已 restore）；且**浮动体尺寸改动会级联**——局部放大/缩小未必单调回收整页。
