## 本轮教训（写入 `MEMORY.md`）

1. **★ `pdftotext` 的默认模式与 `-layout` 模式都会在双栏列边界处跳列**：跨越列边界的**长串**在抽取文本里并不连续，直接做子串匹配会**假性失败**（本轮实测 4 处假阴性，如"…被优先选择的概"后直接跳到另一栏的"及对应搜索参数调整见表 5"）。**回读校验须用"短片段（≤14 字）+ 逐行匹配"**（片段出现在任意一行即算命中）；**英文片段同样须先去空白再比较**，否则会被空格误判。
2. **用户给的是"部分 pre-r14 的版本"**：用户点名的「不主张权重理论最优性」（= 0）、「不等同于」（= 0）等在本轮基线里**已被 r14 清除**。**动笔前先实测计数**，避免重复改造成无效动作或引入新的不一致。
3. **删句前先查该句承担的引用**：E6 若照字面删掉表 2 引用会立刻破坏 `\ref` 覆盖门——**任何"压缩/删除"动作都要先跑一遍引用覆盖与结构检查**。
