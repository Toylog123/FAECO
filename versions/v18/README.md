1. **「用户给定句」需先查同位置是否已有同义句**：用户 §四 写「**增加**核心问题句」，但 r19 已在 §1.1 末放了语义高度重合的句子；照字面追加会产出**两句几乎同义相邻**。正确做法是**先比对同位置现状** → 提出**替换**并说明信息量更强，取得用户确认后再动。
