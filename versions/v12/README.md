## 本轮教训（写入 `MEMORY.md`）

1. **防御性限定语 ≠ 证据，不能一刀切删除**：判据必须含"是否覆盖了审稿人指定落点 / 既有裁定"。保留清单中 **r12 M1/M2/M3 口径表注**与**负结果陈述**是核心不可动项。
2. **"同处三重复述"与"多处各一句必要说明"处置相反**：改前须先分辨是同一处的复述（删重复）还是多个位置的必要覆盖（保位置）。
3. **★ `pdftotext -layout` 在双栏下会把右栏串进左栏句中间**，回读校验会出现"未匹配"**假象**；**回读校验须用按栏阅读顺序抽取**（`-layout` 仅用于内容指纹）。
4. **去防御化的正确落点常是"把理由搬进表"**：E2 的三条"为何不能比"本已逐条列在表 2 中，正文只留指向表 2 的一句 + 正向"我比什么"即可，信息零损失。
5. **`.tex` 写盘纪律仍须遵守**：`read_bytes` → 归一化 CRLF 为 LF → 替换 → 回写 CRLF → 断言 `count(b'\r\r\n') == 0` 且 CR == LF（r13 事故教训）。
