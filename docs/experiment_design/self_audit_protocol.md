# 实验立项自审协议(Self-Audit Protocol)

> 背景:2026-08-06,TCAD 第二轮全方位严格审稿暴露两个本可在第一轮提交前发现的问题:价值定位矛盾(纯 G 不弱于混合)与措辞残留("物理感知"名不副实)。根因不是实验做得不够,而是立项时没有先质疑核心主张、没有把竞争基线做在前面。本文档作为后续所有实验立项与送审前的强制检查项。

## 一、FAECO 教训(按责任排序)

1. 流程中没有独立批判者:审查环节只验证"结果是否真实、是否可复现",不挑战"结果是否支撑论文的核心主张"。审稿人问的是"相比纯 G 到底多了什么价值",这类问题需要主动质疑自己的核心卖点。
2. 竞争基线实验是第一轮审稿才被逼出来的:如果更早做,定位矛盾在第一轮提交前就会暴露,而不是在第二轮被抓。
3. 措辞类修订改了摘要与方法节,但正文残留未清干净:缺少"提交前全文一致性核对"的硬门禁。
4. 赶周期导致反复修上次暴露的问题,从未停下来问:如果核心主张不成立,这篇论文还剩什么。

## 二、强制检查项

### A. 自杀式测试(立项前必须回答)

- [ ] 写清楚:什么实验结果会推翻或削弱本主张?
- [ ] 先跑"最可能推翻主张"的对照,而不是先跑"证明主张"的实验。
- [ ] 反例:FAECO 应先跑纯 G 基线(在写混合修复之前),而不是等审稿人点名。

### B. 竞争基线先行(与主实验同步立项)

- [ ] 主实验立项时,列出全部可能取代主张的基线(纯 G / 纯 R / 纯 B / 随机顺序 / 启发式)。
- [ ] 基线必须与主实验使用相同工具链、相同接受规则、相同停止条件;禁止"穷举到底 vs 提前停止"的不公平对比。
- [ ] 结果不利时,如实写入并重新界定主张边界,不修饰、不淡化。

### C. 主张-证据强度匹配

- [ ] 每个核心主张标注一句"由什么证据支撑、证据类型是什么"(实测 / 工具报告 / 估计模型 / 仿真)。
- [ ] 估计模型(如简化 SPEF)不得写成真实物理证据;仿真不得写成实测。
- [ ] 明确区分"性能提升主张"与"框架/流程主张",后者不需要前者成立。

### D. 措辞与一致性门禁(提交/送审前)

- [ ] 核心术语(物理感知 / 门控 / 负载等)逐处检查是否与证据类型匹配。
- [ ] 摘要 / 结论 / 方法 / 实验四层口径一致。
- [ ] 免责声明与局限性表同步更新。

## 三、触发时机

- 每个新实验立项时(实验设计评审);
- 论文或审稿回复提交前(一致性门禁);
- 任何"重新定位主张"发生时。
