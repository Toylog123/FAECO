## 2. 四个早期方向

| 方向 | 原始设想 | 当前处理 |
|---|---|---|
| 课题一：LLM + 形式化验证的 post-mask functional ECO | 用 LLM 生成 spare-cell patch，用 SAT/Z3 验证 | 暂不作为主线，可作为后续小 demo |
| 课题二：功能-时序协同智能 ECO | 统一功能等价、时序约束和多目标优化 | 保留为中长期扩展 |
| 课题三：物理感知多目标 ECO | 融合 IR-drop、拥塞、布线寄生等物理因素 | 暂不做，工程跨度过大 |
| 课题四：跨设计 ECO 表示学习 | 用自监督/迁移学习提升跨设计泛化 | 暂不做，数据需求过高 |

## 3. 与当前主线的关系

当前主线不是直接采用课题一到四中的任一完整方案，而是从学长 RSECO 工作出发，吸收其中最可落地的部分：

- 从课题二吸收“功能/时序不能割裂”的问题意识；
- 从课题一吸收“形式化验证闭环”的安全边界；
- 从课题三暂时只保留“物理扰动应控制”的论文动机；
- 从课题四暂时只保留“后续可做 ranking/representation learning”的扩展方向。

## 4. 当前主线为什么更合适

| 评估维度 | 原课题二完整方案 | 当前 Failure-Aware RSECO |
|---|---|---|
| 工程复杂度 | 高，需要 GNN/RL/OpenSTA/ABC 同时成立 | 中，先做可复现流程和 cut refinement |
| 数据依赖 | 高，需要大量 ECO 决策数据 | 中，可先用公开 benchmark 构造案例 |
| 论文连续性 | 与学长工作有关但跳跃较大 | 直接继承学长 RSECO 论文 |
| 可控性 | 风险高 | 更容易形成阶段性成果 |

## 5. 结论

课题构想不是废弃，而是作为后续路线池。第一阶段正式主线为 Failure-Aware RSECO；如果该主线跑通，后续可以逐步扩展到功能-时序协同、LLM patch proposal 或 GNN patch ranking。
