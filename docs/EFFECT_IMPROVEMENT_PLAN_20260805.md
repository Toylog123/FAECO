# 效果提升方向评估（2026-08-05）

> 目的：基于真实实验数据，找出当前方法提升空间最大的方向，按 ROI 排序。

## 一、当前真实瓶颈（证据）

1. **物理真实下效果归零**：s382 ideal +0.01 / SPEF 0；b18 ideal +0.13 / SPEF 0（experiments/20260805_parasitic_*）。这是最硬的问题——pre-layout 的修复在寄生 RC 下全没了。
2. **修复幅度小**：8 电路 WNS 改善多在 0.01-0.14（s382 -0.94→-0.93、s420 -1.78→-1.75、s820 -1.42→-1.28），只有 b19 达成 MET。
3. **G 策略在 ideal 网络失效**：大 cell 输入电容拖累前级（*070*→o21a_4 实测变差），upsizing 常被拒。
4. **B 策略 pre-layout 弱**：无长线负载，hold 场景 s27 无改善、s382 才 +0.03。
5. **Hold 是 synthetic**：无真实时钟树/P&R，论文只能标注为受控场景。

## 二、提升方向（按 ROI 排序）

### P0：物理感知闭环（最缺、最影响说服力）
- 接 OpenROAD 完整 P&R（LEF/DEF + clock tree）跑 post-layout，让 G/B 在真实线负载下发挥作用；
- 或至少用真实 routed RC（不只 lumped SPEF）复测现有修复，给出"哪些修复在物理下仍有效"的筛选；
- 这是从"技术报告"升级为"可信 ECO"的关键。

### P1：决策层从"策略选择"升级为"联合动作"（提升修复幅度）
- 现在每轮只接受单一 R/G/B 候选（JOINT 只做了多门 G）；
- 可加"R+G 组合"（关键门重写 + 邻级 sizing）和"多轮多策略序列"（先 R 后 G 的路径级规划），用 OpenSTA 实测选择最优组合；
- s820 已验证多候选联合能超越单门（-1.36→-1.28），组合空间还有明显余量。

### P2：搜索效率（已有基础，继续压）
- adaptive UCB1 已把 STA 从 110 压到 27；可加 warm-start（预训练表 + 在线微调）进一步降探索开销；
- 用"等价类/结构特征"做候选聚类，避免重复测同一类无效修复。

### P3：场景真实性（Hold 升级）
- 在 post-layout 数据上跑真实 hold 修复（min slack 为负的场景），把 synthetic 换成真实；
- 或注入更细的 hold 约束（不同时钟偏移/不确定性分布）做鲁棒性扫描。

## 三、不建议做的事
- 不建议为了"好看"改实验周期/挑电路（会破坏可复现性承诺）；
- 不建议继续堆 pre-layout 单策略实验（边际收益已低，且物理归零问题不解决，加了也弱）。

## 四、一句话结论
当前框架的"搜索/决策/可复现"价值已经立住；效果提升的最大杠杆是**物理感知闭环**（P0），其次是**联合动作空间**（P1）。把这两个做了，论文的"物理真实性"和"修复强度"短板就真正补上了。
