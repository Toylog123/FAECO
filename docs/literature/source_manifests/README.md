# Literature Source Manifests

本目录保存核心文献的机器可读来源与核验状态，不保存未明确允许再分发的论文 PDF。

每个 manifest 至少区分：

- 正确书目信息与 DOI；
- 元数据来源和全文来源；
- 本地文件是否存在、是否与正文一致；
- 证据等级与可用于论文的表述边界；
- 下载、归档和再分发状态。

`web_full_text_verified` 表示已在作者或机构提供的全文页面核对正文，但不等于本地已归档 PDF，也不代表获得再分发许可。

`not_publicly_archived` 表示只找到可核验的正式书目、摘要或问题规范，未找到合法公开全文；此类记录最高按 B 级使用，不能支撑算法细节、复杂度或实验数字。
